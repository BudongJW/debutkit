방송 소프트웨어

첫 방송까지 필요한 소프트웨어 6단계. 단계마다 필수 항목 1개, 나머지는 필요 시 추가. 기준일 2026-11-21, 설치 전 공식 페이지에서 가격과 라이선스 재확인

목차

  • 6단계 요약
  • 필수 확인 2가지
  • 트래킹 프로그램
  • 플랫폼 API
  • 소속사 운영 시 라이선스
  • debutkit 범위

6단계 요약

단계필수처음 추천debutkit 역할
아바타모델 1개VRoid Studio(3D, 무료) 또는 PNG 2장모델 사용 조건 확인
트래킹프로그램 1개, 웹캠Live2D는 VTube Studio, 3D는 VSeeFace설치 확인, OBS 투명 배경 연결

채팅과 후원채팅창한 플랫폼은 내장 위젯, 동시 송출은 debutkit overlay통합 채팅창, 후원 알림
방송 후없음클립 편집 도구(DaVinci Resolve 등)방송 중 자동 클립

필수 확인 2가지

아바타 모델 사용 조건

  • 판매 모델 대부분 개인 활동만 허락
  • 수익 활동, 소속사 활동(법인 사용)은 제작자 별도 허락 필요한 경우 많음
  • VRM 모델은 파일에 조건 포함: debutkit doctor --avatar 모델.vrm --agency

트래킹 프로그램 수익 방송 조건

  • VTube Studio: 무료로 시작, 후원이나 수익 창출이 있는 방송은 유료 버전(DLC) 필요(EULA)
  • VTube Studio: 일정 규모 이상 회사, 소속사는 별도 회사 라이선스 필요
  • VSeeFace: 상업적 이용 허용

소속사 운영 시 라이선스

개인에게 무료인 프로그램도 회사(소속사) 사용 시 조건 변경. 소속 계약 전 확인

대상조건
VTube Studio직전 연도 수입 미화 20만 달러 초과 회사는 Company License(구독형) 필요. 모바일 앱은 기기별 구매
Live2D앱이 사업의 주요 요소이고 연매출 2,000만 엔 초과 시 별도 라이선스 필요 가능
Warudo기업 사용자용 Warudo Pro 별도. 무료 Steam판 회사 사용 조건은 문의 필요
VSeeFace상업적 이용 허용. 회사 대상 별도 제한 없음
아바타 모델법인 사용은 제작자 허락 필요. VRM은 doctor --avatar --agency 로 확인

  • 설치 여부 점검, 설정 연결, 사용 안내만 담당
