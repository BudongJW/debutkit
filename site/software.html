사전 확인 사항

아바타 모델의 사용 조건

  • 판매 모델: 대부분 개인 활동만 허락
  • 수익 활동과 소속사 활동(법인 사용): 대부분 제작자의 별도 허락 필요
  • VRM 모델: 파일에 사용 조건 포함. debutkit doctor --avatar 모델.vrm --agency로 확인 가능

트래킹 프로그램의 수익 방송 조건

  • VTube Studio: 무상으로 시작 가능. 후원이나 수익 창출이 있는 방송은 유료 버전(DLC) 필요(EULA)
  • 일정 규모 이상의 회사, 소속사: VTube Studio 회사 라이선스 필요
  • VSeeFace: 상업 이용 허용

debutkit의 범위

  • 개발 대상 아님: 트래킹 엔진, 송출 프로그램, 3D와 Live2D 모델 제작 도구. 기존 프로그램으로 충분하고, 대부분 독점 소프트웨어로 함께 배포 불가
  • PNGTuber와 3D(VRM) 캐릭터: debutkit 캐릭터 화면에서 직접 표시(오픈소스 three.js, three-vrm 사용)
  • Live2D: 라이선스 조건상 직접 표시 안 함. VTube Studio로 전달. 근거: CHARACTER.md
  • 담당 범위: 설치 여부 점검, 프로그램 간 설정 연결, 이용 안내
  • 전체 목록과 출처: SOFTWARE.md
