배포 파일현재 상태

서명 상태가 바뀌면 이 페이지와 릴리스 노트에 반영합니다.

서명 대상

  • debutkit 프로젝트가 소스와 빌드 절차를 관리하는 파일만 서명합니다: debutkit.exe, debutkit-gui.exe, 설치 프로그램(setup.exe), 제거 프로그램(unins000.exe), macOS debutkit.app
  • 함께 배포하는 외부 오픈소스 구성 요소(Python, Qt for Python, gRPC, NumPy, Pillow 등)는 각 제작자가 배포한 파일을 그대로 포함하며 debutkit의 서명 대상이 아닙니다.
  • Windows 파일에는 제품 이름(debutkit)과 릴리스 버전을 기록합니다. 서명 시 이 값이 릴리스 버전과 일치하는지 확인합니다.

빌드와 승인 절차

  1. 공개 저장소의 릴리스 태그(v버전)에서 GitHub Actions가 GitHub 제공 실행 환경으로 빌드합니다.
  2. 빌드 결과를 서명 서비스에 제출하고, 승인자가 릴리스마다 서명 요청을 직접 승인합니다.
  3. 서명한 파일로 설치, 실행, 제거를 자동 검증한 뒤 릴리스 페이지에 첨부합니다.
  • 개인 PC에서 만든 파일은 서명하지 않습니다.
  • 빌드 절차는 저장소의 .github/workflows/release.yml, 서명 절차는 docs/RELEASING.md에서 확인할 수 있습니다.

개인정보

debutkit은 사용자 또는 프로그램을 설치, 운영하는 사람이 명시적으로 요청한 경우를 제외하고 어떠한 정보도 다른 네트워크 시스템으로 전송하지 않습니다.

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

  • 채팅은 저장하지 않습니다. 사용자가 입력한 채널 주소와 선택 항목은 다음 실행을 위해 이 PC에만 저장하며, API 키와 비밀번호는 저장하지 않습니다.
  • 세부 내용은 사용 설명서의 개인정보와 보안을 참고합니다.

시스템 변경과 제거

  • 설치 프로그램은 현재 사용자 계정에만 설치하며 관리자 권한과 시스템 설정 변경이 필요하지 않습니다.
  • Windows 설정의 앱 목록 또는 시작 메뉴에서 제거할 수 있습니다. 제거 시 프로그램 파일과 시작 메뉴 항목을 삭제합니다.
  • 다른 프로그램과 함께 쓰는 ffmpeg 폴더, 사용자가 저장한 클립은 제거 시 삭제하지 않습니다.
