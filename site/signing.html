서명 현황

배포 파일현재 상태
Windows 설치 프로그램, 압축 파일인증서 확보 전으로 서명 없이 배포. 실행 시 SmartScreen 경고 표시 가능
macOS 앱(debutkit.app)임시 서명(ad-hoc)과 강화된 런타임 적용. 공증 미적용으로 첫 실행 시 Gatekeeper 경고 표시

서명 상태 변경 시 이 페이지와 릴리스 노트에 반영

서명 대상

  • 서명 대상: debutkit 프로젝트가 소스와 빌드 절차를 관리하는 파일. debutkit.exe, debutkit-gui.exe, 설치 프로그램(setup.exe), 제거 프로그램(unins000.exe), macOS debutkit.app
  • 서명 제외: 함께 배포하는 외부 오픈소스 구성 요소(Python, Qt for Python, gRPC, NumPy, Pillow 등). 각 제작자가 배포한 파일 그대로 포함
  • Windows 파일 정보: 제품 이름(debutkit)과 릴리스 버전 기록. 서명 시 릴리스 버전과의 일치 여부 확인

빌드와 승인 절차

  1. 공개 저장소의 릴리스 태그(v버전) 기준으로 GitHub Actions가 GitHub 제공 실행 환경에서 빌드
  2. 빌드 결과를 서명 서비스에 제출. 승인자가 릴리스마다 서명 요청 직접 승인
  3. 서명한 파일로 설치, 실행, 제거 자동 검증 후 릴리스 페이지에 첨부
  • 개인 PC에서 만든 파일은 서명 대상 아님
  • 절차 문서: 빌드는 저장소의 .github/workflows/release.yml, 서명은 docs/RELEASING.md

개인정보

debutkit은 이용자 또는 프로그램을 설치, 운영하는 사람의 명시 요청이 없으면 어떠한 정보도 다른 네트워크 시스템으로 전송하지 않음

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

기능연결 대상연결 조건
채팅 수신치지직, SOOP, Twitch, YouTube 서버채널 또는 방송 주소를 입력하고 오버레이를 시작한 경우
치지직 로그인치지직 Open API로그인을 실행한 경우
VTube Studio 연동이 PC의 VTube Studio(127.0.0.1)연결, 모델 불러오기, 후원 반응을 이용하는 경우
YouTube 연결 확인YouTube Data API연결 확인을 실행한 경우
업로드 속도 측정speed.cloudflare.com측정을 실행한 경우
새 버전 확인api.github.com확인 버튼 또는 --check-update를 실행한 경우
ffmpeg 다운로드github.com다운로드를 실행하거나 설치 과정에서 선택한 경우
  • 이용 통계, 오류 보고, PC 정보의 자동 전송 없음
  • 채팅 저장 없음
  • 이용자가 입력한 채널 주소와 선택 항목: 다음 실행용으로 이 PC에만 저장. 설정 파일에 API 키와 비밀번호 저장 안 함
  • 로고 만들기의 API 키, 바로 방송의 스트림 키, 팬 커뮤니티의 Cloudflare 토큰: 이 PC에만 암호화 저장(Windows 데이터 보호, 다른 운영체제는 운영체제 키 보관소)
  • 캐릭터 음성 반응: OBS가 계산한 마이크 음량 수치만 사용. 음성 저장, 전송 없음
  • 웹캠 얼굴 추적: 이용자가 연 브라우저 창 안에서 영상 처리, 숫자 값만 이 PC의 debutkit 서버로 전송
  • 함께 배포하는 MediaPipe의 사용 기록 전송: 콘텐츠 보안 정책으로 차단
  • 오류 기록(처리되지 않은 오류, 연결과 클립 저장 같은 상태 안내): 이 PC의 기록 폴더에만 저장, 전송 없음. 문제 제보 시 이용자가 직접 첨부
  • 세부 내용: 사용 설명서의 개인정보와 보안

시스템 변경과 제거

  • 설치 범위: 현재 사용자 계정. 관리자 권한, 시스템 설정 변경 불필요
  • 제거 방법: Windows 설정의 앱 목록 또는 시작 메뉴
  • 제거 시 삭제 항목: 프로그램 파일, 시작 메뉴 항목
  • 제거 시 유지 항목: 다른 프로그램과 함께 쓰는 ffmpeg 폴더, 이용자가 저장한 클립
