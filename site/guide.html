설치

Windows 설치 프로그램

  1. 릴리스 페이지에서 debutkit-버전-windows-x64-setup.exe 다운로드 후 실행
  2. 추가 작업 화면에서 필요 항목 선택. 자동 클립 이용 시 ffmpeg 다운로드(약 115 MB) 선택
  3. 설치 완료 후 시작 메뉴의 debutkit 실행
  • 설치 위치: 현재 사용자 계정(관리자 권한 불필요)
  • 명령줄 도구 debutkit.exe: 설치 폴더에 포함
  • 제거: Windows 설정의 앱 목록
  • 다운로드한 ffmpeg: 다른 프로그램과 함께 쓰는 폴더에 저장, 제거 대상에서 제외
  • 코드 서명 미적용으로 SmartScreen 경고 표시 가능. 추가 정보 선택 후 실행

Windows 압축 파일

  1. 릴리스 페이지에서 debutkit-버전-windows-x64.zip 다운로드
  2. 원하는 폴더에 압축 해제
  3. debutkit-gui.exe(설정 마법사) 또는 debutkit.exe(명령줄) 실행

macOS, Linux 실행 파일

운영체제파일실행
macOS(Apple Silicon)debutkit-버전-macos-arm64.zip압축 해제 후 debutkit.app 실행. 명령줄은 debutkit.app/Contents/MacOS/debutkit
Linux(x64)debutkit-버전-linux-x64.tar.gz압축 해제 후 debutkit/debutkit-gui(설정 마법사) 또는 debutkit/debutkit(명령줄) 실행
  • macOS: 공증 미적용(임시 서명만 적용)으로 첫 실행 시 Gatekeeper 경고 표시. Finder에서 debutkit.app 우클릭 후 열기 선택
  • Linux: Qt 실행에 그래픽 라이브러리 필요. Ubuntu, Debian 설치 명령은 sudo apt install libxcb-cursor0 libxkbcommon-x11-0
  • OBS 원격 제어, 채팅창, 자동 클립: Windows와 동작 동일
  • Linux에서 아바타 창 캡처 소스가 없는 OBS: 아바타 소스 생략 후 안내

설정 마법사

  • 실행: 시작 메뉴의 debutkit, debutkit-gui 또는 debutkit gui
  • 단계 이동: 왼쪽 단계 목록 또는 다음 버튼
단계내용
PC 점검이 단계를 열면 자동으로 점검. ffmpeg가 없으면 ffmpeg 다운로드 버튼 표시(Windows). 업로드 속도 측정 버튼
캐릭터캐릭터 등록(파일, 폴더), PNG 이미지로 만들기, 방송에 사용할 캐릭터 지정, 3D 캐릭터 동작(기본 동작, 후원 반응), VTube Studio와 Warudo로 보내기, 사용 조건 확인
OBS 장면WebSocket 포트, 비밀번호, 아바타 프로그램을 지정해 장면 생성
채팅과 알림플랫폼별 채널 입력, 치지직 로그인, 자동 클립과 채팅 명령 선택 후 오버레이 시작. 실행 중 추첨 조작 화면, 로고 만들기 열기
마무리다음 할 일(시작하기 화면 열기), 단계별 준비 상태, 자동 클립 저장 폴더, 새 버전 확인, 저장한 설정 삭제, 문제 제보(점검 결과 복사, 기록 폴더 열기)
  • 설정 마법사 종료 시 오버레이와 자동 클립도 함께 종료
  • OBS 비밀번호, 치지직 Client Secret, YouTube API 키: 파일 저장 안 함

저장한 설정

  • 저장 시점: 오버레이 시작, 장면 생성, 창 닫기
  • 저장 항목: 채널 주소, 포트, 선택 항목(이 PC에 저장)
  • 다음 실행 시 저장한 값 자동 적용. 채널 저장 시 채팅과 알림 단계부터 시작
  • 방송마다 오버레이 시작만 누르면 준비 완료
  • 저장 위치: Windows %APPDATA%\debutkit\settings.json, macOS ~/Library/Application Support/debutkit/settings.json, Linux ~/.config/debutkit/settings.json
  • 삭제: 마무리 단계의 저장한 설정 삭제 버튼 또는 debutkit settings --clear

방송 시작 버튼

  • 방송에 필요한 프로그램(OBS, VTube Studio 등), 폴더, 사이트(치지직 스튜디오 등)를 정해 둔 순서로 실행
  • 메신저, 게임 런처처럼 방송에 방해되는 프로그램은 먼저 종료
  • 방송 종료 후 꺼 둔 프로그램 다시 실행
  1. 설정 마법사 마무리 단계의 방송 시작 버튼 카드에서 세팅 편집 누름
  2. 켤 것 목록에 프로그램, 바로가기, 폴더를 끌어다 놓거나 파일, 폴더, 사이트 버튼으로 추가. 위에서부터 차례로 실행, 항목마다 다음 항목까지 대기 시간 지정(무거운 프로그램은 넉넉하게)
  3. 끌 것 목록: 켜진 프로그램에서 고르거나 프로그램 이름(예: Discord.exe, KakaoTalk.exe) 입력. 바로가기를 놓으면 대상 프로그램 이름으로 변환
  4. 프로그램 창을 원하는 자리와 크기(모니터, 최대화 포함)로 둔 뒤 지금 창 위치 기억 누름. 다음 실행부터 그 자리에 창 표시(Windows)
  5. 저장 후 방송 전에 켜기, 방송이 끝나면 방송 끝 누름
세팅게임, 작업, 노래 방송처럼 상황별로 여러 개. 복제로 새 세팅 작성, 백업 파일로 다른 PC에 이전
끄는 방식창 닫기 요청을 보내고 6초 안에 남아 있으면 강제 종료. 운영체제, 보안 프로그램, debutkit, 보호 목록의 프로그램은 끄지 않음
이미 켜진 프로그램다시 켜지 않음(선택: 창만 기억한 자리로 옮기기)
사이트Edge(없으면 Chrome)의 새 창으로 열고 기억한 자리로 옮김
다시 켜짐 알림꺼 둔 프로그램이 방송 중에 다시 켜지면 카드에 표시(선택: 다시 끄기)
켠 뒤선택: OBS WebSocket 연결 확인(최대 60초), 채팅과 알림 단계 설정으로 오버레이 시작
방송 끝이번 방송에 끈 프로그램을 다시 켜고 감시 중지(세팅에서 해제 가능)
  • 명령줄: debutkit launch add 방송 "C:/Program Files/obs-studio/bin/64bit/obs64.exe" https://studio.chzzk.naver.com, debutkit launch add 방송 Discord.exe --stop, debutkit launch(켜기), debutkit launch end(방송 끝)
  • 창 위치 기억: debutkit launch remember
  • macOS, Linux: 켜기와 끄기만 지원

캐릭터

방송용 캐릭터 등록과 사용 조건 확인

  • PNGTuber, 3D(VRM, GLB, FBX): debutkit 캐릭터 화면으로 바로 방송
  • Live2D: VTube Studio로 보내 방송

종류별 처리

종류등록할 파일방송
PNGTuber입 다문 이미지와 입 벌린 이미지(투명 PNG). 눈 감은 이미지 2장 선택debutkit 캐릭터 화면. 말하면 입 벌린 이미지로 바뀌고 무작위로 눈 깜빡임
3D(VRM 0.x, 1.0).vrm 파일debutkit 캐릭터 화면(입 움직임, 눈 깜빡임, 호흡, 웹캠 얼굴 추적). 손과 몸 추적이 필요하면 Warudo, VMagicMirror, VSeeFace(VRM 0.x만)
3D(GLB, FBX)사람 모양 뼈가 있는 .glb, .fbx(Mixamo, VRoid, Unreal, Blender, MMD 등의 뼈 이름). FBX 텍스처는 같은 폴더에 두거나 파일에 포함debutkit 캐릭터 화면(VRM과 같은 움직임). 다른 방송 프로그램에는 VRM 변환 필요
Live2Dmodel3.json이 있는 폴더 또는 zipVTube Studio. 방송 프로그램으로 보내기로 모델 폴더에 복사
Inochi2D.inp, .inxInochi Session에서 불러오기
  • 등록 시 파일을 이 PC의 캐릭터 보관함(설정 폴더의 characters)에 복사
  • VRM: 파일에 기록된 사용 조건(사용 허용 대상, 상업적 이용, 법인 사용)을 읽어 수익 방송, 소속사 활동 제한 여부 표시
  • GLB, FBX, Live2D, PNG: 파일에 사용 조건 없음. 판매처, 제작자 약관 직접 확인 필요
  • GLB, FBX에 입 모양이나 눈 감기 표정이 없으면 등록 시 안내
  • ARKit 표정(퍼펙트 싱크)이 있는 모델: 그 표정으로 입과 눈을 움직임. 입 모양 없이 턱 뼈만 있으면 턱을 움직임
  • 시험용 debutkit 기본 캐릭터 데비 동봉(PNGTuber, 3D(VRM) 2종)
  • 3D 데비: CC0 VRoid 샘플의 색을 데비 색으로 바꾼 모델. 누구나 방송, 수익 방송, 수정 가능

캐릭터 만들기

  • PNGTuber: 같은 크기의 투명 PNG로 입 다문 모습과 입 벌린 모습을 그린 뒤 설정 마법사의 PNG로 만들기 이용
  • VRM으로 그림 만들기(설정 마법사 캐릭터 단계의 그림 만들기(VRM), 주소 /character/sheet)
    • 등록한 VRM을 이 PC에서 그림(모델 파일은 밖으로 보내지 않음)
    • 표정 시트: 정면, 3/4, 얼굴, 표정 7종(기본, 기쁨, 화남, 슬픔, 편안, 아, 눈 감음). 무대 배경, 시트 그림 저장 가능
    • 추천 자세: 편하게 서기, 손 인사, 허리에 손, 만세, A 자세(PNGTuber 4상태도 같은 자세)
    • 포즈 그림: 몸, 머리, 왼팔, 오른팔, 다리를 따로 골라 조합. 잠금과 랜덤 포즈, 표정, 각도(정면, 살짝 옆, 3/4)
    • 포즈 그림 저장: 1024x1536 PNG. 무대 배경을 끄면 투명(썸네일, 방송 화면 꾸미기에)
    • 부위 8개: 허리, 상체, 머리, 왼팔, 오른팔, 왼손, 오른손, 다리(선택지 76개). 손 모양은 자연스럽게, 쫙 펴기, 주먹, 브이, 가리키기, 엄지 척, 고양이 손, 오케이
    • 추천 자세 10종: 편하게 서기, 손 인사, 허리에 손, 만세, 브이, 노래하기, 입 가리고 웃기, 고양이 손, 부끄러움, A 자세
    • 예시: 부위 옆 예시 단추로 그 부위의 선택지를 그림으로 보고 눌러서 고름(손은 손을 들어 가까이)
    • 자세 보정: 팔꿈치나 손목이 몸에 묻힌 팔을 바깥으로 조금씩 돌림
    • 자세 파일 저장(JSON): three-vrm 자세 형식. 자세 파일 불러오기에서 다시 읽거나 다른 VRM에 적용
    • 관절 직접 돌리기: 관절(목, 머리, 어깨, 팔, 손목, 다리 등)을 골라 막대로 더 돌림. 오른쪽은 거울이라 같은 값이면 양쪽이 같은 동작
    • 자세 파일 불러오기: VRMA(동작 시점 고르기)와 MMD 포즈 파일 VPD. MMD 팔 각도로 팔 높이 보정. 파일은 브라우저 안에서만 읽음
    • MMD의 다리 IK로 만든 다리 자세는 VPD에 들어 있지 않으면 적용되지 않음(다리 뼈 회전이 있는 VPD만)
    • 내 자세 저장: 지금 자세를 이름으로 저장하고 다시 불러오기(이 PC 설정 폴더, 50개까지)
    • VMC로 자세 보내기: Warudo, VSeeFace, VMagicMirror의 VMC 받기(포트 39539)를 켜고 같은 VRM을 불러 둔 뒤 보내기 시작. 지금 자세와 표정이 그대로, 자세를 바꾸면 바로 반영
    • 얼굴 추적 VMC 송신(/vmc)과 함께 켜면 머리와 표정은 얼굴 추적 값. 이 화면을 닫으면 20초 안에 멈춤
    • PNGTuber 4상태(입 다묾, 입 벌림, 눈 감음, 입 벌리고 눈 감음)를 투명 배경 1024px로 만들어 바로 등록
    • 등록한 그림 캐릭터는 원본 VRM의 작성자와 사용 조건을 그대로 따름
    • VRoid Studio로 만든 VRM이면 그 품질 그대로 그림이 됨
    • 모델 점검: 감정 표정, 입 모양, 눈 깜빡임, 퍼펙트 싱크, 텍스처 무게(그래픽 메모리 추정)
    • 가벼운 사본: 텍스처를 1024px 이하로 줄인 새 캐릭터. 게임과 함께 방송할 때 그래픽 메모리 약 절반(원본은 그대로, 수정 금지 모델은 만들지 않음)
  • 3D: VRoid Studio(무료, 한국어, Windows와 macOS)에서 제작 후 VRM으로 내보내기. VSeeFace와 함께 이용 시 VRM 0.0, 소속사 활동 예정 시 법인 사용 조건 지정이 가능한 VRM 1.0 선택
  • Linux: VRoid Studio Linux판 없음. Vket Avatar Maker(웹) 또는 Blender와 VRM Add-on 이용. Vket Avatar Maker 제작 모델은 저작권이 HIKKY에 있고 법인, 소속사 사용은 HIKKY의 사전 확인 필요
  • 뼈가 없는 3D 모델: Mixamo(무료, Adobe 계정)에서 뼈 자동 삽입 후 FBX로 받아 등록. Mixamo 원본 파일은 타인 배포 불가

debutkit 캐릭터 화면으로 방송

  1. 캐릭터 단계에서 캐릭터 선택 후 방송에 사용 누름
  2. OBS 장면 단계에서 아바타 프로그램을 debutkit 캐릭터 화면으로 선택 후 장면 생성. 직접 추가 시 브라우저 소스 주소에 http://127.0.0.1:8790/character 입력
  3. 채팅과 알림 단계에서 오버레이 시작. OBS 설정의 마이크 음량이 기준(기본 -40 dB)을 넘으면 캐릭터가 말하는 모습으로 전환
  • 잡음에 입이 움직일 때: 기준 상향(-30 등)
  • 말해도 반응이 없을 때: 기준 하향. 명령줄: debutkit overlay --voice-threshold -35
  • OBS 마이크 외 다른 오디오 소스 이용 시 --voice-input 소스이름 지정
  • 미리보기: 오버레이 실행 중 설정 마법사의 미리보기 버튼(말하기 동작 반복)
  • 기준 조정: 시작하기 화면(http://127.0.0.1:8790)의 캐릭터 화면 카드에서 현재 OBS 마이크 음량(dB)과 말하기 상태를 보며 지정
  • 말하기 시험 버튼: 3초 동안 말하는 모습 표시

웹캠 얼굴 추적

  • 추적 대상: 3D(VRM) 캐릭터의 머리 움직임, 양쪽 눈, 입, 웃음
  • PNGTuber: 눈 깜빡임과 입 벌림에 반영
  • OBS 브라우저 소스는 카메라 이용 불가. 추적은 일반 브라우저 창에서 진행
  1. 오버레이 실행 상태에서 설정 마법사의 얼굴 추적 창 열기 누름 또는 브라우저(Chrome, Edge)에서 http://127.0.0.1:8790/tracker 열기
  2. 추적 시작 누름, 카메라 사용 허용. 카메라가 여러 대이면 목록에서 선택
  3. 추적 창을 열어 둔 채 OBS 이용. 창을 닫거나 최소화하면 0.6초 뒤 캐릭터가 기본 움직임으로 복귀
  • 카메라 영상: 브라우저 창 안에서만 처리. debutkit 서버로는 숫자 값(머리 각도, 눈, 입, 웃음)만 전송
  • 영상 저장, 전송 없음
  • 추적 엔진: Google의 오픈소스 MediaPipe Face Landmarker(Apache-2.0), 프로그램에 포함
  • MediaPipe 내장 사용 기록 전송: 추적 화면의 보안 정책으로 차단
  • 거울처럼 움직이기(기본): 고개를 돌린 방향과 화면 속 방향 일치
  • Live2D 캐릭터의 얼굴 추적: VTube Studio 담당

휴대폰 얼굴 추적(아이폰)

  • 아이폰 얼굴 인식 카메라(ARKit)로 추적한 머리 움직임과 표정 52개를 캐릭터에 반영
  • 웹캠 대비 눈, 입, 눈썹 움직임 정확
  • 휴대폰 앱: iFacialMocap(App Store 유료, FaceMotion3D는 iFacialMocap 호환 모드) 또는 VTube Studio(아이폰, 아이패드)
  1. 휴대폰과 PC를 같은 Wi-Fi(공유기)에 연결
  2. 휴대폰 앱 실행. VTube Studio는 설정 첫 번째 탭 맨 아래의 3rd Party PC Clients 켜기. 앱 화면에 표시된 IP 주소 확인
  3. 오버레이 실행 상태에서 설정 마법사의 휴대폰 얼굴 추적 누름 또는 브라우저에서 http://127.0.0.1:8790/phone 열기
  4. 앱 종류와 휴대폰 IP 주소 입력 후 연결 시작 누름. 첫 연결 시 Windows 보안 경고가 나오면 개인 네트워크 허용
  5. 휴대폰이 비스듬하면 화면을 정면으로 보는 자세에서 지금 자세를 정면으로 누름
  • 연결 설정 저장, 다음 오버레이 실행 시 자동 연결. 연결 끊기를 누르면 다음 실행부터 자동 연결 안 함
  • 휴대폰 값 수신 중에는 웹캠 추적 창의 값 미사용
  • 퍼펙트 싱크: ARKit 이름 표정(eyeBlinkLeft, jawOpen 등)이 있는 3D 캐릭터는 눈썹, 볼, 코, 혀까지 얼굴 전체가 움직임. 웹캠 추적도 같은 방식으로 반영
  • 머리가 반대로 돌 때: 거울처럼 움직이기 변경. 위아래가 반대일 때: 위아래 반전 선택
  • 연결 실패 시 확인 사항: Windows 네트워크 프로필(개인 네트워크), 아이폰의 로컬 네트워크 허용, 같은 앱 값을 받는 다른 프로그램(VSeeFace, Warudo 등) 종료

VMC 송신(Warudo, VSeeFace, VMagicMirror)

  • debutkit의 얼굴 추적 값(웹캠 추적 창, 휴대폰 얼굴 추적)을 VMC 프로토콜로 다른 프로그램에 송신
  • 송신 항목: 머리 회전, 양쪽 눈, 입, 웃음, 퍼펙트 싱크 표정 52개
  1. 받는 프로그램에서 VMC 수신 켜기(Warudo의 VMC 수신, VSeeFace의 VMC protocol receiver, VMagicMirror의 외부 트래킹). 기본 포트 39539
  2. 오버레이 실행 상태에서 설정 마법사 캐릭터 단계의 VMC 송신 누름 또는 http://127.0.0.1:8790/vmc 열기
  3. 주소(같은 PC는 127.0.0.1)와 포트 확인 후 송신 시작 누름. 켜 두면 다음 오버레이 실행 때도 자동 시작
  • 받는 곳: 이 PC 또는 같은 네트워크의 내부 주소만 지정 가능
  • 다른 PC로 송신 시 받는 PC의 방화벽에서 UDP 포트 허용
  • 얼굴 인식 실패 중에는 송신 중지(받는 프로그램은 마지막 자세 유지)
  • 좌우가 반대로 움직일 때: 좌우 반전 선택
  • 명령줄: debutkit vmc start --host 127.0.0.1 --vmc-port 39539, debutkit vmc status, debutkit vmc stop

debutkit 휴대폰 앱

  • 휴대폰 앞면 카메라로 얼굴을 추적해 머리 움직임과 표정 52개를 PC로 보내는 debutkit 전용 앱
  • 다른 회사 앱 없이 안드로이드 휴대폰에서도 휴대폰 얼굴 추적 이용 가능
  • PC 없이 휴대폰만으로 방송: 휴대폰만으로 바로 방송 참고
  1. 안드로이드: 릴리스 페이지의 debutkit-phone-버전-android.apk를 휴대폰에서 다운로드해 설치(출처를 알 수 없는 앱 설치 허용). 아이폰: 앱 스토어 배포 전이므로 Mac과 Xcode로 직접 빌드(저장소의 mobile/ios/README.md)
  2. PC에서 http://127.0.0.1:8790/phone#remote 열기, 휴대폰 조작 화면을 켠 뒤 새 휴대폰 QR 만들기 누름
  3. 앱에서 QR 코드 찍기를 누르고 PC 화면의 QR 코드 촬영. 앱과 PC에 같은 확인 번호가 보이면 PC에서 승인
  4. 앱의 추적 시작 누름, 휴대폰을 얼굴 정면 30에서 50cm 거리에 세워 둠
  • 카메라 영상: 휴대폰 안에서만 처리, 숫자 값만 전송
  • 값마다 휴대폰에만 있는 비밀값으로 서명. PC는 승인한 휴대폰의 값만 사용
  • 거울처럼 움직이기, 위아래 반전, 정면 맞추기: 휴대폰 연결 화면의 휴대폰 얼굴 추적 설정 적용
  • 앱 값 수신 중에는 웹캠 추적 창의 값 미사용
  • 추적 중 화면 꺼짐 없음. 화면 어둡게로 배터리 소모와 발열 감소, 휴대폰 과열 시 송신 횟수 자동 감소
  • 안드로이드 앱: 현재 시험용 서명. 새 버전은 이전 앱 삭제 후 설치

앱의 카메라 영상 모드: 휴대폰 카메라 영상을 OBS로 직접 송신(SRT보다 지연이 짧고 암호 입력 불필요)

  1. OBS 실행 후 http://127.0.0.1:8790/phone#camera의 앱 영상용 OBS 소스 만들기 누름 또는 debutkit camera setup --app 실행. 현재 방송 장면에 [DK] 휴대폰 카메라(앱) 브라우저 소스 생성(평소 투명)
  2. 앱에서 카메라 영상 선택, 앞면 또는 뒷면 카메라 지정 후 보내기 시작 누름
  • 영상: 휴대폰과 OBS 사이 직접 전송, 외부 서버 경유 없음
  • 소리: 송신 안 함, PC 마이크 사용
  • OBS 소스를 다시 불러오거나 Wi-Fi가 잠시 끊기면 앱이 자동 재연결
  • 공유기가 기기 사이 통신을 막으면(손님용 Wi-Fi 등) 연결 불가

  1. 설정 마법사 캐릭터 단계의 3D 캐릭터 동작 카드에서 동작 파일 추가 누름. zip은 안의 동작 파일 전체 등록. 명령줄: debutkit motion add 파일
  2. 기본 동작에서 대기 중 반복할 동작 선택. 없음은 기본 움직임(호흡, 흔들림). 명령줄: debutkit motion idle 동작
  3. 후원 반응에 동작과 최소 금액 지정 후 오버레이 시작. 명령줄: debutkit overlay --motion-reaction 1000:동작
  4. 오버레이 실행 중 즉시 실행: 한 번 실행 버튼, 시작하기 화면의 동작 버튼, debutkit motion play 동작
  • FBX, GLB: 뼈 이름(Mixamo, VRoid, Unreal, Blender, MMD 등) 기준으로 캐릭터의 뼈에 맞춰 변환
  • 이동 거리는 캐릭터 키 기준으로 조정, A자 자세 캐릭터는 팔 방향 보정
  • 동작에 든 입 모양, 눈 감기, 웃음 표정은 미사용(목소리, 눈 깜빡임, 얼굴 추적 우선)
  • BVH 동작: VRM 공식 변환 도구 bvh2vrma로 VRMA 변환 후 등록
  • PNGTuber 캐릭터: 동작 미적용

  4. 후원 반응에 단축키 이름과 최소 금액 지정 후 시험 실행으로 확인. 오버레이 시작 후 조건에 맞는 후원, 멤버십 알림 때 단축키 실행

  • Twitch 비트, 외화 후원: 최소 금액 0(모든 후원) 규칙에만 반응

  • VTube Studio 토큰: 이 PC의 설정 폴더(vts-token.json)에만 보관. 삭제: debutkit vts logout

  • 시그니처 판 모양 5종: 둥근 카드, 원, 하트, 별, 꽃 배지(테두리도 모양을 따라감)
  • 배너 자르기: 큰 그림이나 움짤을 올리고 바탕 꽉 채우기로 놓은 뒤 SOOP 연결 배너로 저장
  • 시그니처 풍선 그림: 단위(별풍선, 애드벌룬, 원, bits), 금액, 이름을 넣고 후원 벽 시그니처로 등록. 같은 단위와 금액이 있으면 그림과 이름만 바꿈. 움짤을 저장한 뒤 방금 만든 움짤로 등록을 켜면 바깥이 투명한 움직이는 시그니처
  • 올린 그림은 이 브라우저 안에서만 사용하고 서버로 보내지 않음
  • 규격은 플랫폼 안내 기준. 올리기 전에 플랫폼 화면에서 다시 확인

휴대폰 카메라 영상

  • 휴대폰 카메라 영상(실사, 손 캠, 방 안 촬영)을 같은 Wi-Fi로 받아 OBS 소스로 표시
  • OBS 기본 미디어 소스의 SRT 수신 기능 이용, 플러그인 불필요
  • 송신 앱: Larix Broadcaster(아이폰, 안드로이드 무료) 등 SRT 송신 앱
  1. OBS 실행 후 설정 마법사 OBS 장면 단계의 휴대폰 카메라 소스 추가 누름 또는 debutkit camera setup 실행. 현재 방송 장면 왼쪽 위에 [DK] 휴대폰 카메라 소스 생성
  2. 휴대폰과 PC를 같은 Wi-Fi에 연결, 표시된 QR 코드를 휴대폰 카메라로 찍어 Larix Broadcaster에 연결 정보 가져오기. 오버레이 실행 중에는 http://127.0.0.1:8790/phone#camera에서도 QR 코드 확인 가능
  3. Larix의 방송 버튼(빨간 원)을 누르면 OBS에 영상 표시. OBS 첫 수신 시 Windows 보안 경고가 나오면 개인 네트워크 허용
  • 암호가 맞는 휴대폰만 연결(SRT 암호화, AES-128)
  • 암호: 이 PC의 설정 폴더에만 보관. 새 암호 생성 시 휴대폰 앱에 재등록
  • 소리: 송신 안 함, PC 마이크 사용

  • 영상 지연 시 5GHz Wi-Fi 이용. 끊김이 잦으면 지연 여유 확대(기본 200밀리초)

시작하기 화면과 OBS에 넣기

  • 방송 준비 목록: 오버레이를 켜면 열리는 시작하기 화면(http://127.0.0.1:8790) 맨 위
  • 구성: 진행 막대와 할 일 5개(debutkit 켜기, OBS 연결, 채팅창과 알림과 캐릭터를 OBS에 넣기, 시험 후원으로 확인, 방송 모양 고르기)
  • OBS 연결, OBS에 넣은 화면은 자동 확인. 모두 끝나면 목록 접기로 접어 둠
  1. OBS 실행 후 OBS 위 메뉴의 도구, WebSocket 서버 설정에서 WebSocket 서버 사용 켜기(OBS 28 이상에 포함)
  2. 서버 비밀번호를 설정 마법사의 OBS 장면 단계에 입력 후 오버레이 켜기. 화면 오른쪽 위에 OBS 연결됨과 지금 장면 이름 표시
  3. 방송 화면마다 있는 OBS에 넣기 누름. 지금 OBS 장면에 그 화면 추가, 이름([DK] 채팅 등), 크기, 자리 자동 지정
  • 후원 알림처럼 소리가 나는 화면: OBS로 오디오 보내기와 오디오 모니터링(모니터와 출력)도 함께 설정. 방송과 내 헤드폰 양쪽으로 소리 출력
  • 이미 있는 화면: 주소(채팅창의 표시 형태 등)만 갱신, 장면에 중복 추가 안 함
  • 설정 마법사의 장면 만들기로 만든 화면도 같은 이름 사용
  • OBS 연결 실패 시 할 일과 함께 끌어다 놓기 링크 표시
  • 링크를 OBS의 소스 목록으로 끌어다 놓으면 이름과 크기를 지정한 브라우저 소스 생성(OBS를 관리자 권한으로 실행했다면 불가). 주소 복사로 직접 추가도 가능
  • 위쪽 메뉴 묶음: 시작하기, 꾸미기(방송 화면, 후원 알림), 방송 중 놀이(후원 추첨, 뽑기판, 후원 벽, 참여 레이스), 팬과 함께(팬 커뮤니티, 디스코드 합방), 더 보기(휴대폰, OBS 없이 방송, 로고 만들기, VMC 송신). 선택한 묶음의 화면은 그 아래 줄에 표시
  • OBS, 장면, 브라우저 소스, WebSocket 같은 용어 옆의 ? 단추: 용어 풀이 표시
  • 방송 직전 점검(방송 준비 목록 아래, 방송할 때마다 확인)
    • OBS 연결

    • 알림 소리의 방송, 내 헤드폰 출력 여부(음소거, 모니터링)
    • 채팅 연결(플랫폼별 연결됨과 받은 채팅 수, 끊김 이유, 데모 채팅만 있는지)

알림 꾸미기

  • 후원, 구독 알림의 표시 형태와 소리 지정
  • 바꾼 설정은 OBS 소스 새로고침 없이 방송 화면에 즉시 반영
  1. 시작하기 화면의 후원, 구독 알림 카드에서 알림 꾸미기 누름 또는 http://127.0.0.1:8790/alerts/control 열기
  2. 스타일(방송 스타일 따르기 또는 알림만 다른 스타일), 배치, 위치, 등장 움직임, 표시 시간, 크기 선택
  3. 후원 문구와 구독 문구 입력. {name}은 후원자 이름, {amount}는 금액 자리
  4. 금액 구간 추가 후 구간마다 그림, 강조 효과, 표시 시간, 효과음 지정. 그림은 그림 올리기로 먼저 업로드
  5. 미리보기에서 작은 후원, 큰 후원, 별풍선, 구독 예시 확인 후 저장. 방송 화면으로 시험 알림: OBS의 알림 소스에 시험 후원 송신
  • 추천 모양 5가지(기본 카드, 크게 가운데, 아래 띠, 말풍선, 금액별로 다르게): 배치, 위치, 움직임, 효과음, 금액 구간 일괄 입력(문구와 올린 그림은 유지)
  • 처음 상태로: 기본값으로 복원. 추천 모양, 처음 상태로 모두 저장 후 방송 화면에 반영
  • 저장하지 않은 변경이 있으면 저장 단추에 바뀐 내용 있음 표시. 저장 없이 화면을 닫으면 브라우저 확인 창 표시
  • 추천 모양, 배치 단추의 그림 견본: 저장한 문구와 스타일로 그린 실제 알림 모습(소리 없이 이 화면에서만 표시)
  • 배치 6종: 카드, 가로 띠(화면 아래 한 줄), 말풍선, 큰 글자(바탕 없음), 그림 옆 글자, 그림 위 카드
  • 강조 효과 5종: 반짝이, 종이 조각, 흔들림, 빛 번짐, 크게. 큰 후원 구간에만 넣으면 금액별로 연출 차등
  • 금액 구간: 원 기준(SOOP 별풍선 1개 100원으로 계산). Twitch 비트, 외화 후원은 최소 금액 0 구간 적용
  • 효과음 5종(차임, 동전, 팡파르, 퐁, 방울): 브라우저에서 합성. OBS 브라우저 소스 속성의 OBS 오디오 제어를 켜면 방송에 송출
  • 올린 그림(PNG, GIF, WebP, JPEG, 8 MB 이하, 30개까지): 이 PC의 설정 폴더 alert-images에만 보관. 그림 삭제 시 그 그림을 쓰던 구간은 그림 없이 표시

후원 추첨

  • 후원 시 상품표에서 확률대로 추첨, 방송 화면에 선택한 연출로 표시
  • 연출: 카드 뒤집기, 룰렛, 캡슐 뽑기, 즉석 복권, 티켓 출력, 추첨기, 타로
  • 평소에는 투명, 추첨할 때만 화면 아래쪽에 표시
  • 구성: 마스코트 마이(리본 마이크) 문양을 찍은 카드, 무대용 상품 룰렛, 후원자와 금액을 표시하는 하단 띠
  1. 오버레이 시작 후 시작하기 화면의 후원 추첨 카드에서 추첨 설정과 시험 추첨 열기. 설정 마법사에서는 채팅과 알림 단계의 후원 추첨 설정 버튼 누름
  2. 상품표에 상품 이름과 가중치 입력. 가중치는 비율, 확률 자동 계산
  3. 추첨 규칙에 최소 금액과 추첨 횟수 입력. 예: 1,000원 이상 1회, 10,000원 이상 11회
  4. 연출, 결과 표시 시간, 추첨 이름(예: 벌칙 룰렛), 표시 위치(아래 가운데, 왼쪽 아래, 오른쪽 아래), 크기 지정 후 후원이 오면 추첨(사용) 체크, 저장
  5. 시험 추첨으로 방송 화면 확인. debutkit scenes로 만든 장면에는 후원 추첨 소스 포함. 직접 추가 시 브라우저 소스 주소에 http://127.0.0.1:8790/draw 입력
  • 금액: 원 기준(SOOP 별풍선 1개 100원으로 계산). Twitch 비트, 외화 후원은 최소 금액 0 규칙에만 반응
  • 규칙 적용 방식 선택: 금액 이상이면 가장 큰 규칙(기본), 금액이 정확히 같을 때만. 구독, 멤버십도 1회 추첨 가능
  • 상품 등급 표시: 확률 5% 이하는 희귀 상품(금색), 이름에 꽝이 들어간 상품은 꽝(줄무늬), 나머지는 일반(핑크)
  • 카드 연출 순서: 카드 펼침, 희귀 카드만 금색 빛으로 미리 표시, 일반 카드부터 뒤집기, 희귀 카드는 마지막에 천천히 뒤집기. 미리 표시는 실제 결과와 항상 일치
  • 룰렛: 칸 경계의 못에 걸려 휘는 플래퍼와 테두리 전구 연출. 칸이 좁은 상품은 번호와 옆 범례로 표시
  • 효과음(선택): 브라우저에서 합성, OBS 브라우저 소스 속성의 OBS 오디오 제어를 켜면 방송에 송출
  • 확률 표시(선택): 카드와 범례에 확률 표시
  • 추첨 방식: 이 PC의 debutkit이 운영체제 난수로 추첨, 여러 화면에 같은 결과 표시. 여러 후원이 겹치면 하나씩 차례로 연출
  • 최근 결과: 읽을 문장(대본) 함께 표시, 복사 가능. 결과는 파일 저장 없이 최근 100개만 메모리에 보관
  • 미리보기: /draw?sample=card&count=11, /draw?sample=wheel(저장한 설정으로 예시 추첨을 그 화면에서만 표시). &bg=light는 밝은 배경 위 확인용
  • 글꼴: 함께 배포한 한글 글꼴(모두 SIL OFL)을 프로그램에 포함, 인터넷 연결 없이 표시. 상품 이름과 안내 글은 공통 글꼴 목록에서 각각 선택
  • 소품 연출: 캡슐 뽑기(손잡이를 돌릴 때마다 등급 색 캡슐), 즉석 복권(동전으로 은박 긁기, 희귀 칸은 마지막에 천천히), 티켓 출력(등급 색 램프와 출력), 추첨기(구슬 색이 등급), 타로(카드를 섞어 한 장씩 펼치고 오늘의 한마디). 연출마다 모양 3종
  • 꾸미기: 결과 뒤 효과(종이 조각, 색 테이프, 불꽃놀이, 무대 조명, 하트, 별), 상품 이름과 안내 글의 글꼴과 크기. 타로의 한마디는 직접 입력하거나 기본 문장
  • 연출 모양 32종: 캡슐 뽑기 8(둥근 유리 돔, 네모 유리창, 검정, 민트 레트로, 레몬 상자, 하늘 유리, 금빛, 사탕 상자), 즉석 복권 6(은박 깔끔, 거칠게, 검정, 파스텔, 금박, 민트), 티켓 출력 8(입장권, 영수증, 교환권, 공연 티켓, 영화표, 탑승권, 상품권, 가게 영수증), 추첨기 5(핑크 팔각, 나무, 검정, 민트, 금빛), 타로 3
  • 연출, 모양 선택: 그림 단추(저장한 상품표로 뽑은 예시, 소리 없이 이 화면에서만 재생)
  • 결과 뒤 효과, 글꼴, 타로 한마디, 추첨 이름, 위치와 크기: 자세히를 펼쳐 변경
  • 추천 상품표 4가지(감사 인사, 벌칙 룰렛, 노래 신청, 꽝 없이): 상품표 자동 입력
  • 처음 상태로: 상품표, 규칙, 연출을 처음 값으로 복원(사용 여부는 유지). 추천 상품표, 처음 상태로 모두 저장 후 반영
  • 저장하지 않은 변경: 저장 단추에 표시
  • 대본 새 창(/draw/script): 읽을 문장을 큰 글자로 표시. 기록 화면(/draw/log): 최근 결과와 상품별 합계
  • 대기 중인 추첨이 3개 이상이면 연출 속도 상향

시청자 참여 추첨

  • 채팅으로 참가자 모집 후 당첨자 추첨 또는 참가자 순서 지정
  • 결과: 후원 추첨과 같은 방송 화면(/draw)에 당첨 카드나 순서표로 표시
  1. 추첨 조작 화면의 시청자 참여 추첨에서 참가 명령(기본 !참가), 추첨 이름, 후원 참가 최소 금액(선택) 지정 후 모집 시작 누름. 지난 명단은 삭제
  2. 모집 중 방송 화면 아래에 모집 띠(참가 명령, 참가 인원)와 새 참가자 이름 표시. 채팅에 참가 명령을 입력한 시청자가 플랫폼과 닉네임 기준으로 1번씩 참가
  3. 당첨 인원 지정 후 당첨자 뽑기 누름 또는 순서 정하기 누름. 모집 중이면 자동 마감 후 추첨
  • 후원 참가: 최소 금액 이상 후원한 시청자 자동 참가(원 기준, 별풍선 1개 100원). 0원은 모든 후원
  • 명단 편집: 시청자 제외, 이름 직접 추가 가능. 명단은 파일 저장 안 함, 최대 1,000명
  • 순서 정하기: 전체 순서를 섞고 방송 화면에는 앞에서 30명까지 표시
  • 미리보기: /draw?sample=raffle(당첨 카드), /draw?sample=order(순서표), /draw?sample=recruit(모집 띠)
  • 명령줄: debutkit raffle start --keyword !참가 --donation-min 5000, debutkit raffle status, debutkit raffle draw 3, debutkit raffle draw --order, debutkit raffle stop

휴대폰 조작 화면

  • 같은 Wi-Fi의 휴대폰 브라우저로 시청자 참여 추첨(모집 시작, 마감, 당첨자 뽑기, 순서 정하기)과 3D 캐릭터 동작 조작
  • 후원 추첨 최근 결과(읽을 문장) 확인
  • 앱 설치 불필요
  1. 오버레이 실행 상태에서 설정 마법사의 휴대폰 조작 화면 버튼 누름 또는 http://127.0.0.1:8790/phone#remote 열기
  2. 이 PC 주소(공유기 주소, 보통 192.168로 시작) 선택 후 켜기 누름. 처음 켤 때 Windows 보안 경고가 나오면 개인 네트워크 허용
  3. 새 휴대폰 QR 만들기 누름, 휴대폰 카메라로 QR 코드를 찍어 조작 화면 열기
  4. 휴대폰과 PC의 등록 기기 목록에 같은 4자리 확인 번호가 보이면 PC에서 승인 누름. 이후 휴대폰에서 같은 주소를 열면 바로 이용
  • 조작 권한: QR로 등록하고 PC에서 승인한 휴대폰만
  • QR이 방송 화면에 노출되어도 승인 전에는 조작 불가. QR 하나로 5분 동안 1대만 등록
  • 요청마다 휴대폰에만 있는 비밀값으로 서명. 비밀값은 QR 코드로만 전달, 네트워크 전송 없음
  • 화면 내용은 암호화하지 않음. 같은 Wi-Fi의 다른 기기가 열람은 가능하나 조작은 불가
  • 뽑기, 순서 정하기: 오조작 방지용으로 다시 눌러야 실행
  • 등록 기기: 최대 5대. PC에서 삭제하면 즉시 차단
  • PC 주소 변경 시(공유기 변경 등) 조작 화면을 다시 켜고 휴대폰 재등록
debutkit remote start --address 192.168.0.5   # 켜기(기본 포트 8792)
debutkit remote pair                          # 새 휴대폰 등록 주소(5분 유효)
debutkit remote status                        # 등록 기기와 확인 번호
debutkit remote approve 기기                   # 승인(remove로 삭제)

방송 연출(뽑기판, 후원 벽, 참여 레이스, 주사위 판)

  • 뽑기판, 후원 벽, 참여 레이스: 오버레이와 함께 켜지는 방송 화면

만들기

  1. Cloudflare 무료 계정 생성. 카드 등록 불필요
  2. Cloudflare 대시보드의 내 프로필, API 토큰에서 토큰 만들기 누름, "Cloudflare Workers 편집" 템플릿 선택 후 권한에 계정 D1 편집을 추가해 생성
  3. 오버레이 실행 상태에서 http://127.0.0.1:8790/community/control(이동 막대의 커뮤니티) 열기, 커뮤니티 이름, 주소 이름(예: dotori-fans), 스트리머 이름, API 토큰 입력 후 올리기 누름
  4. 커뮤니티 주소(https://주소이름.계정이름.workers.dev)가 나오면 관리 화면 열기로 스트리머 로그인, 이용 규칙, 소개, 개인정보 담당 연락처 지정
  • 토큰: 이 PC에만 암호화 보관(Windows DPAPI)
  • 같은 주소 이름으로 다시 올리면 글과 회원은 유지, 커뮤니티 프로그램과 설정만 갱신
  • 무료 한도: 하루 요청 10만 번, 데이터베이스 5 GB, 그림 저장 1 GB(그림 하나 3 MB 이하). 처음 시작하는 채널에는 충분, 한도 초과 시 그날은 일시 중지
  • 명령줄: debutkit community deploy --script dotori-fans --name "도토리네 쉼터"(토큰은 CLOUDFLARE_API_TOKEN), community status, community notice 제목 --pin, community admin, community live on
  • 올리기 전 화면 미리보기: debutkit community preview(Node.js 22.5 이상, 시험용 데이터, 이 PC에서만)

시청자 가입과 로그인

  • 방송 채팅 인증(설정 불필요)
    • 커뮤니티의 로그인에서 이용 규칙과 개인정보 처리방침 동의, 만 14세 이상 확인 후 숫자 6자리 표시
    • 방송 중 채팅에 !인증 숫자 입력 시 debutkit이 채팅을 확인해 그 채팅 계정(치지직, SOOP, YouTube, Twitch)으로 가입 처리
    • 이메일, 비밀번호 없음
  • 채팅의 스트리머, 매니저: 커뮤니티에서도 스트리머, 매니저 권한 부여
  • 닉네임을 바꿔도 플랫폼 계정 번호로 동일인 식별
  • 방송이 없을 때의 가입: 치지직, 디스코드, 구글 로그인 켜기
  • 플랫폼 로그인 설정: 서비스별 개발자 화면에서 앱 생성, Client ID와 Secret을 커뮤니티 화면의 플랫폼 로그인에 입력 후 다시 올리기, 화면에 나온 돌아올 주소를 앱에 등록
  • 네이버, 카카오 로그인: 서비스 검수 필요로 미포함
  • 로그인한 시청자: 내 정보에서 다른 채팅 계정 추가 연결 가능. 이미 다른 회원에 연결된 계정은 연결 불가

방송 연동

  • 채팅 !출석: 커뮤니티에 연결한 시청자에게 하루 한 번 포인트 지급, 방송 화면에 출석 카드 표시
  • 커뮤니티의 출석 체크: 별도로 하루 한 번, 연속 출석 시 추가 점수
  • 방송 중 표시: 실제 플랫폼 채팅이나 후원이 처음 오면 커뮤니티 맨 위에 방송 중 표시(방송 주소 링크), 오버레이를 멈추면 해제. 커뮤니티 화면의 단추로 직접 켜기, 끄기 가능
  • 방송에 띄우기: 스트리머나 매니저가 커뮤니티 글의 방송에 띄우기를 누르면 OBS 브라우저 소스 http://127.0.0.1:8790/community(권장 크기 1920x1080)에 글과 팬아트를 방송 스타일 카드로 차례로 표시
  • 참여 추첨: 추첨 조작 화면에서 모집 시작 시 커뮤니티에도 참가 단추 표시, 커뮤니티 참가자도 명단에 추가
  • 공지, 방송 일정: 커뮤니티 화면에서 등록
  • 일정 종류: 매주 일정, 그날만 일정(특별 방송, 휴방). 커뮤니티 홈의 이번 주 방송에 표시
  • 방송 화면 미리보기의 시험 채팅으로 !인증, !출석을 방송 없이 시험 가능(시험 계정으로 참여)

OBS 없이 바로 방송

  • 캐릭터, 채팅, 후원 알림, 추첨 연출을 한 화면에 모은 송출 화면을 OBS 없이 치지직, SOOP, YouTube, Twitch로 직접 송출
  • 송출 방식: 송출 화면 창(Edge 앱 창)을 ffmpeg로 캡처, 하드웨어 H.264와 마이크 소리로 송출
  • 게임 화면 캡처, 장면 전환 미지원. 게임 방송은 OBS 이용
  • 지원 환경: Windows 10(1903 이상), Windows 11

준비

  1. ffmpeg 준비(debutkit setup --ffmpeg 또는 설정 마법사의 ffmpeg 다운로드 버튼)
  2. 오버레이 실행 상태에서 설정 마법사의 OBS 없이 바로 방송 버튼 누름 또는 http://127.0.0.1:8790/broadcast/control 열기
  3. 방송 플랫폼 선택, 스트림 키 붙여 넣기 후 키 저장 누름. 치지직과 SOOP은 방송 설정 화면의 송출 서버 주소(rtmp://로 시작)도 입력. YouTube와 Twitch는 기본 주소 사용
  4. 마이크 선택, 송출 화면 열기로 화면 확인 후 방송 시작 누름

이용 시 유의 사항

  • 송출 화면 창: 방송 화면 그 자체
  • 다른 창에 가려져도 송출 유지. 최소화하면 방송 화면 멈춤(다시 띄우면 이어서 송출)
  • 방송 중 창을 닫으면 약 10초 뒤 방송 종료. 창 크기 축소 시 화질 저하
  • 권장 화질: 720p 30fps
  • 인코더: NVIDIA, Intel, AMD 그래픽의 하드웨어 인코더 중 이 PC 지원 인코더 자동 선택, 없으면 CPU(x264). PC 성능 부족 시 조작 화면에 경고 표시
  • 후원 알림 효과음과 음악 송출: Windows 소리 설정에서 스테레오 믹스를 켜고 함께 보낼 소리 장치로 선택
  • 방송 시작 20초 이후 연결이 끊기면 자동 재연결. 시작 직후 종료 시 조작 화면에 원인(서버 주소, 스트림 키 등) 표시
  • 창 캡처 요건: 그래픽 장치(D3D11). 그래픽 드라이버가 없는 가상 머신 등에서는 안내 문장 표시, OBS 이용
  • 스트림 키 유출 시 타인이 내 채널로 방송 가능. 키를 방송 화면에 띄우지 않음, 노출 시 방송 플랫폼에서 키 재발급
debutkit broadcast set --platform chzzk --server rtmp://(치지직 스트림 URL)
debutkit broadcast key        # 스트림 키 입력(화면에 표시하지 않음)
debutkit broadcast devices    # 녹음 장치와 인코더
debutkit broadcast set --mic "마이크 이름" --quality 720p30
debutkit broadcast start      # 방송 시작(stop으로 끝내기)

휴대폰만으로 바로 방송(안드로이드)

  • debutkit 휴대폰 앱의 바로 방송 탭: PC 없이 휴대폰에서 직접 송출
  • 송출 내용: 캐릭터 화면(debutkit 기본 캐릭터 또는 고른 그림 두 장이 마이크 소리에 맞춰 입을 움직임) 또는 카메라 영상, 마이크 소리
  1. 앱의 바로 방송 탭에서 방송 플랫폼 선택, 스트림 키 붙여 넣기 후 키 저장 누름. 치지직과 SOOP은 방송 설정 화면의 송출 서버 주소도 입력
  2. 방송 화면에서 캐릭터 화면 또는 카메라 영상 선택. 캐릭터 화면은 배경색, 왼쪽 위 글자, 캐릭터 그림(입 닫은 그림과 입 연 그림, 투명 배경 PNG 권장), 입 움직임 민감도 지정. 카메라 영상은 휴대폰을 가로로 들고 방송
  3. 화질 선택 후 방송 시작 누름. 첫 실행 시 마이크(카메라 영상이면 카메라)와 알림 사용 허용
  • 방송 중 화면 꺼짐 없음. 다른 앱으로 전환하거나 화면을 꺼도 송출 유지
  • 중지: 알림의 방송 끝내기
  • 모바일 데이터 사용량: 720p 기준 1시간 약 1.2 GB
  • 연결이 느리면 비트레이트 자동 하향, 방송 중 연결이 끊기면 5초 뒤 재연결
  • 휴대폰 과열 시 영상 비트레이트 하향. 장시간 방송은 충전기 분리, 케이스 제거 상태 권장
  • 채팅, 후원 알림 표시: 미지원. 아이폰 앱의 바로 방송은 다음 버전 이후 제공 예정

자동 클립

준비

  1. ffmpeg 준비: Windows는 debutkit setup --ffmpeg 또는 설정 마법사의 ffmpeg 다운로드 버튼(약 115 MB, SHA-256 검증), macOS는 brew install ffmpeg, Linux는 배포판 패키지 관리자
  2. debutkit scenes --replay-buffer로 OBS 리플레이 버퍼 설정 후 OBS 재시작
  3. 오버레이와 함께 실행: debutkit overlay --chzzk-api --clip

저장 기준

채팅 급증방송별 평소 채팅량보다 크게 증가한 시점. 시청자가 적은 방송에도 적용
표시 명령스트리머, 매니저의 !clip, !클립 입력. 시청자의 입력은 무시
동시 송출모든 플랫폼 채팅을 합산해 판단. YouTube 채팅은 요청 간격 때문에 최대 10초 늦게 반영
저장 위치동영상/debutkit-clips. --clip-dir로 변경
결과 표시시작하기 화면의 채팅창 미리보기와 설정 마법사의 기록 영역

방송 없이 시험: 시작하기 화면의 스트리머 !clip 버튼

클립 길이

  • 리플레이 버퍼 최대 시간보다 긴 클립: 버퍼 길이로 저장, 안내 표시
  • 버퍼 연장: OBS 설정의 출력 탭에서 리플레이 버퍼 최대 시간 연장 또는 scenes --replay-buffer 120으로 재설정

움짤과 세로 쇼츠

  • 저장한 클립이나 다른 영상으로 움짤(GIF, WebP)과 세로 쇼츠(1080x1920 MP4, 소리 포함) 제작
  • 결과: 원본 옆에 저장. 같은 이름이 있으면 번호를 붙여 덮어쓰기 방지
  • 자동 클립과 함께: 설정 마법사의 클립마다 움짤(GIF), 클립마다 세로 쇼츠를 선택하거나 debutkit overlay --clip --clip-gif --clip-shorts. 움짤은 클립 앞 6초, 폭 480
  • 직접 만들기: debutkit clip gif 클립.mp4 --start 3 --duration 5, debutkit clip webp 클립.mp4(Pillow 필요), debutkit clip shorts 클립.mp4 --mode crop --focus 0.8
  • 쇼츠 형태: blur 흐린 배경 위에 원본(기본), crop 세로로 자르기(--focus 0은 왼쪽, 1은 오른쪽. 캐릭터가 있는 쪽), fit 위아래 여백
  • 워터마크: --watermark 로고.png --watermark-position bottom-right --watermark-size 18 --watermark-opacity 85. 방송 로고 만들기의 투명 PNG를 그대로 사용

치지직 공식 API

  • 본인 채널의 채팅, 후원, 구독을 네이버 공식 Open API로 수신
  • 비공식 수신 대비 연결 끊김이 적고 후원 정보 정확

애플리케이션 등록

  1. 치지직 개발자 센터에서 애플리케이션 등록
  2. 로그인 리디렉션 주소에 http://localhost:8765/callback 등록
  3. API 사용 범위에서 채팅, 후원, 구독 관련 항목 선택
  4. Client ID와 Client Secret 확인

로그인

  • 설정 마법사: 채팅과 알림 단계의 치지직 API 입력란에 Client ID와 Client Secret 입력 후 치지직 로그인 버튼 누름
  • 명령줄: 아래 명령 실행
$env:CHZZK_CLIENT_ID = "Client ID"
$env:CHZZK_CLIENT_SECRET = "Client Secret"
debutkit chzzk login
debutkit overlay --chzzk-api
  • 브라우저에서 동의하면 토큰 발급, 이 PC의 사용자 설정 폴더에 보관. 만료 시 자동 갱신
  • Client ID, Client Secret: 토큰 갱신에 사용. 실행할 때마다 환경 변수 또는 입력란에 지정 필요(파일 저장 안 함)
  • 로그아웃(토큰 삭제): debutkit chzzk logout

YouTube 채팅

  • YouTube 방송의 채팅, 슈퍼챗, 슈퍼스티커, 멤버십 정보를 공식 YouTube Data API로 수신
  • 요건: Google Cloud에서 발급한 API 키

API 키 발급

  1. Google Cloud 콘솔에서 프로젝트 생성
  2. API 라이브러리에서 YouTube Data API v3 사용 설정
  3. 사용자 인증 정보에서 API 키 생성. API 제한은 YouTube Data API v3로 설정 권장

실행

  • 설정 마법사: 채팅과 알림 단계의 YouTube 입력란에 방송 주소와 API 키 입력
  • 명령줄: 아래 명령 실행
debutkit overlay --youtube https://www.youtube.com/watch?v=영상ID --youtube-key API키
debutkit overlay --youtube 영상ID --youtube-interval 15
  • 방송 주소: 방송마다 바뀌는 영상 주소 입력(채널 주소 미지원)
  • API 키: --youtube-key 또는 환경 변수 YOUTUBE_API_KEY로 지정. 요청 머리글로만 전송, 저장 안 함
  • 연결 시점 이전의 지난 채팅은 미표시, 연결 이후 채팅부터 표시

연결 확인

  • 방송 전 API 키와 수신 방식 확인
  • 요건: 방송 중인 영상 주소. 할당량 약 11 단위 소모
  • 설정 마법사: YouTube 입력란 옆의 연결 확인 버튼
debutkit youtube check https://www.youtube.com/watch?v=영상ID --youtube-key API키

방송 주소영상 ID 해석없음
API 키, 라이브 채팅API 키 유효 여부, 방송 중인 라이브 채팅 존재 여부1 단위
요청 방식채팅 1회 조회, YouTube 권장 요청 간격5 단위

스트리밍 방식만 실패해도 기본 설정(auto)은 요청 방식으로 전환해 채팅 수신

수신 방식

--youtube-mode방식할당량
auto(기본)스트리밍 우선, 이용 불가 시 요청 방식으로 자동 전환스트리밍 기준
stream스트리밍(streamList, gRPC). 연결을 유지하며 새 채팅을 즉시 수신연결 1회 5 단위
poll요청 방식(liveChatMessages.list). --youtube-interval 간격(기본 10초, 최소 5초)으로 조회요청 1회 5 단위, 1시간 약 1,800 단위

할당량

  • 기본 할당량: 일일 10,000 단위, 태평양 시간 자정에 초기화
  • 스트리밍: 연결 유지 중 추가 사용량 없음, 긴 방송에 적합. 연결이 끊기면 마지막 위치부터 재연결
  • 요청 방식: 기본 간격 10초 기준 약 5시간 분량. 긴 방송은 간격 확대 또는 Google Cloud에서 할당량 증설 신청
  • 스트리밍 요건: grpcio, protobuf(설치 프로그램과 실행 파일에 포함)

바로 방송이 바로 끝남조작 화면의 이유 확인. 스트림 키와 송출 서버 주소를 방송 플랫폼의 방송 설정 화면에서 다시 복사. 인코더 오류면 인코더를 x264로 변경

AI 심볼 만들기 실패화면의 이유 확인. AI Horde가 오래 걸리면 대기열 위치가 줄어드는지 확인(익명은 가장 뒤 순서), 작업자가 없다는 안내면 나중에 다시 시도, 안전 필터 안내면 설명 변경. 키 오류면 서비스에서 키를 다시 복사해 저장, 한도 초과나 잔액 부족이면 서비스의 결제 상태 확인(Hugging Face 무료 GPU 한도는 첫 사용 24시간 뒤 다시 채워짐), 응답 멈춤이나 혼잡이면 잠시 뒤 다시 시도, 안전 정책이면 설명 변경.
