설치

Windows 설치 프로그램

  1. 릴리스 페이지에서 debutkit-버전-windows-x64-setup.exe 다운로드, 실행
  2. 추가 작업 화면: 자동 클립을 쓰면 ffmpeg 내려받기 선택(약 115 MB), 바탕 화면 바로 가기 선택
  3. 설치 후 시작 메뉴의 debutkit 실행(설정 마법사)
  • 현재 사용자 계정에 설치. 관리자 권한 불필요
  • 명령줄 도구 debutkit.exe 는 설치 폴더에 포함
  • 제거: Windows 설정의 앱 목록에서 debutkit 제거. 내려받은 ffmpeg는 다른 프로그램과 같이 쓰는 폴더라 남김
  • 코드 서명 미적용. SmartScreen 경고 시 추가 정보 선택 후 실행

Windows 압축 파일

  1. 릴리스 페이지에서 debutkit-버전-windows-x64.zip 다운로드
  2. 원하는 폴더에 압축 해제
  3. debutkit-gui.exe 실행(설정 마법사). 명령줄은 같은 폴더의 debutkit.exe
  • 설치 없이 실행. 파이썬, 관리자 권한 불필요

OBS 장면

준비

  1. OBS 실행
  2. 도구 메뉴의 WebSocket 서버 설정에서 WebSocket 서버 사용 체크
  3. 비밀번호 사용 시 --password 또는 환경 변수 OBS_WEBSOCKET_PASSWORD
  4. 처음 구성 시 장면 모음 메뉴에서 새 장면 모음 생성 권장
debutkit scenes --replay-buffer
debutkit scenes --dry-run

  • 리플레이 버퍼를 처음 켠 경우 OBS 재시작 후 사용 가능

  • 세부 꾸밈: 브라우저 소스 속성의 사용자 지정 CSS
  • 테스트 채팅, 테스트 후원: 외부 전송 없이 설정 화면과 OBS에만 표시

자동 클립

준비

  1. ffmpeg 준비: debutkit setup --ffmpeg 또는 마법사 PC 점검 화면의 ffmpeg 내려받기(Windows, 약 115 MB, SHA-256 확인). macOS는 brew install ffmpeg, Linux는 패키지 관리자
  2. OBS 리플레이 버퍼 켜기: debutkit scenes --replay-buffer 후 OBS 재시작
  3. 오버레이와 함께 실행: debutkit overlay --chzzk-api --clip

저장 기준

  • 채팅 급증: 방송별 평소 채팅량 대비 크게 증가한 순간. 시청자가 적은 방송에도 적용
  • 표시 명령: 방장, 매니저의 !clip, !클립. 시청자 명령은 무시
  • 동시 송출: 모든 플랫폼 채팅 합산
  • 저장 위치: 동영상/debutkit-clips. --clip-dir 로 변경
  • YouTube 채팅도 합산(요청 간격 때문에 최대 10초 늦게 반영)
  • 결과: 설정 화면 채팅 미리보기와 마법사 기록 칸에 표시
  • 방송 없이 시험: 설정 화면의 방장 !clip 버튼

클립 길이

  • 리플레이 버퍼 최대 시간보다 긴 클립은 버퍼 길이로 저장, 안내 표시
  • 늘리는 방법: OBS 설정의 출력 탭에서 리플레이 버퍼 최대 시간 변경 또는 scenes --replay-buffer 120

치지직 공식 API

내 채널의 채팅, 후원, 구독을 네이버 공식 Open API로 수신. 시청자 읽기보다 안정적이고 후원 정보 정확

애플리케이션 등록

  1. 치지직 개발자 센터에서 애플리케이션 등록
  2. 로그인 리디렉션 주소에 http://localhost:8765/callback 등록
  3. API 사용 범위에서 채팅, 후원, 구독 관련 항목 선택
  4. Client ID, Client Secret 확인

로그인

마법사: 채팅과 알림 단계의 치지직 API 칸에 Client ID, Client Secret 입력 후 치지직 로그인. 명령줄:

$env:CHZZK_CLIENT_ID = "Client ID"
$env:CHZZK_CLIENT_SECRET = "Client Secret"
debutkit chzzk login
debutkit overlay --chzzk-api
  • 브라우저에서 동의하면 토큰 발급. 이 PC 사용자 설정 폴더에 보관, 만료 시 자동 갱신
  • Client ID, Client Secret은 토큰 갱신에 사용. 실행할 때마다 환경 변수 또는 마법사 입력 칸 필요, 파일 저장 없음
  • 로그아웃(토큰 삭제): debutkit chzzk logout

YouTube 채팅

YouTube 방송의 채팅, 슈퍼챗, 슈퍼스티커, 멤버십을 공식 YouTube Data API로 수신. Google Cloud의 API 키 필요

API 키 발급

  1. Google Cloud 콘솔에서 프로젝트 생성
  2. API 라이브러리에서 YouTube Data API v3 사용 설정
  3. 사용자 인증 정보에서 API 키 만들기. API 제한을 YouTube Data API v3로 설정 권장

실행

마법사: 채팅과 알림 단계의 YouTube 칸에 방송 주소, API 키 입력. 명령줄:

debutkit overlay --youtube https://www.youtube.com/watch?v=영상ID --youtube-key API키
debutkit overlay --youtube 영상ID --youtube-interval 15
  • 방송 주소: 방송마다 바뀌는 영상 주소. 채널 주소는 지원 안 함
  • API 키: --youtube-key 또는 환경 변수 YOUTUBE_API_KEY. 요청 머리글로만 전송, 저장 안 함
  • 표시 시작: 연결 직후의 지난 채팅은 표시하지 않고 그 뒤 채팅부터 표시
  • 자동 클립: 다른 플랫폼 채팅과 합산해 판단

할당량

  • 기본 할당량: 하루 10,000 단위(태평양 시간 자정 초기화)
  • 채팅 요청 1회 5 단위. 기본 간격 10초 기준 1시간 약 1,800 단위, 약 5시간 방송 가능
  • 긴 방송: --youtube-interval 로 간격 늘리기(최소 5초) 또는 Google Cloud에서 할당량 증설 신청
  • YouTube가 더 긴 간격을 요구하면 그 간격을 따름

문제 해결

포트 사용 중다른 프로그램이 8790 사용. overlay --port, scenes --overlay-port 에 같은 새 번호 지정
리플레이 버퍼 사용 불가설정을 처음 켠 경우 OBS 재시작
자동 클립 ffmpeg 필요debutkit setup --ffmpeg 실행 또는 마법사 ffmpeg 내려받기
클립이 짧음OBS 리플레이 버퍼 최대 시간 늘리기
치지직 로그인 실패Client ID, Secret 확인. 개발자 센터 리디렉션 주소와 --redirect 일치. 8765 포트 사용 프로그램 종료
YouTube 할당량 초과태평양 시간 자정까지 대기. 다음 방송부터 --youtube-interval 늘리기

업로드 속도 낮음유선 연결, 다른 기기의 업로드 중지 후 다시 측정. 추천보다 낮은 비트레이트 사용
아바타가 안 보임아바타 프로그램 실행 확인. 게임 캡처 속성의 투명도 허용, 창 선택 확인
SmartScreen 경고추가 정보 선택 후 실행. 불안하면 파이썬 패키지로 설치

해결되지 않는 문제: GitHub 이슈에 debutkit doctor --json 결과와 함께 등록

개인정보와 보안

  • 사용 통계 전송 없음. 새 버전 확인은 직접 실행할 때만 GitHub에 연결
  • 업로드 속도 측정은 직접 실행할 때만 Cloudflare 측정 서버(speed.cloudflare.com)에 임의 데이터 전송(최대 31 MB). PC 정보 전송 없음
  • YouTube API 키는 실행 중에만 사용하고 저장하지 않음
  • 오버레이 서버는 127.0.0.1에서만 열림. 다른 웹사이트의 요청은 Host, Origin 확인으로 차단
  • 채팅 저장 없음. 화면 표시용 최근 30개만 메모리에 유지
  • 자동 클립의 급증 판단은 닉네임을 해시로만 사용
  • 치지직 토큰은 이 PC 사용자 설정 폴더에만 보관
  • 비공식 시청자 읽기(--chzzk, --soop)는 플랫폼 승인 방식 아님. 내 치지직 채널은 공식 API 권장
