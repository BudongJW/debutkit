debutkit

버튜버 방송 준비용 오픈소스 소프트웨어. 첫 방송 전에 필요한 PC 점검, OBS 장면 구성, 채팅창과 후원 알림 연결, 방송 중 자동 클립 기능을 하나의 프로그램으로 제공합니다.

다운로드(Windows, macOS, Linux) 사용 설명서
버전
0.7.1
지원 환경
Windows 64비트(설치 프로그램, zip), macOS(Apple Silicon), Linux(x64)
방송 플랫폼
치지직, SOOP, Twitch, YouTube
필요 프로그램
OBS Studio 28 이상
라이선스
Apache-2.0

기능

설정 마법사에서 모든 기능을 사용할 수 있으며, 같은 기능을 명령줄로도 제공합니다.

기능내용명령
PC 점검메모리, CPU, 그래픽카드, 저장 공간, 마이크, 웹캠, OBS, 트래킹 프로그램, ffmpeg 점검 및 조치 안내. 아바타 모델(VRM) 사용 조건 확인, 업로드 속도 측정과 비트레이트 추천doctor
OBS 장면 구성대기 화면, 본방송, 토크, 자리 비움, 엔딩 장면 생성. 아바타 투명 배경 캡처, 채팅창과 후원 알림 연결, 기존 장면 유지scenes
채팅창과 후원 알림치지직, SOOP, Twitch, YouTube 채팅을 OBS 브라우저 소스 하나에 표시. 후원, 구독, 슈퍼챗, 멤버십 알림. 표시 형태 5종overlay
방송 중 자동 클립채팅이 방송별 평소 수준보다 크게 증가하거나 스트리머, 매니저가 !clip을 입력하면 OBS 리플레이 버퍼를 클립으로 저장. 동시 송출 시 전 플랫폼 채팅 합산overlay --clip
공식 API 연동치지직 Open API 로그인(본인 채널의 채팅, 후원, 구독), YouTube Data API 라이브 채팅chzzk login
준비 도구ffmpeg 다운로드(SHA-256 검증), 새 버전 확인setup

화면

실제 프로그램 화면. 채팅 내용과 점검 결과는 예시입니다.

설치

배포 형태Windows 설치 프로그램(setup.exe)과 압축 파일(zip), macOS 앱(debutkit.app), Linux 압축 파일(tar.gz). 설정 마법사와 명령줄 도구 포함
지원 환경Windows 64비트(Windows 11에서 검증), macOS 11 이상(Apple Silicon), Linux x64(Ubuntu 22.04 이상 기준)
설치 방식현재 사용자 계정에 설치, 시작 메뉴 등록. 관리자 권한과 파이썬 불필요
선택 구성 요소ffmpeg(자동 클립용). 설치 과정 또는 설정 마법사에서 다운로드
코드 서명Windows 미적용(SmartScreen 경고가 표시될 수 있음). macOS 임시 서명, 공증 미적용(첫 실행 시 Gatekeeper 경고). 코드 서명 정책
파이썬 패키지모든 운영체제에서 사용 가능. Python 3.10 이상

설치 절차

  1. 릴리스 페이지에서 debutkit-버전-windows-x64-setup.exe 다운로드
  2. 설치 프로그램 실행. 자동 클립을 사용할 경우 ffmpeg 다운로드 선택
  3. 시작 메뉴에서 debutkit 실행
  4. 설정 마법사의 단계별 안내에 따라 진행

설치 없이 사용하려면 debutkit-버전-windows-x64.zip의 압축을 해제한 뒤 debutkit-gui.exe를 실행합니다. macOS와 Linux 설치 방법은 사용 설명서에 있습니다.

파이썬 패키지

pip install "debutkit[gui] @ git+https://github.com/BudongJW/debutkit"
debutkit-gui

운영 원칙

무상 공개모든 기능을 Apache-2.0으로 공개. 소속 프로그램 참여 여부와 무관
정보 수집 없음사용 통계 미전송. 오버레이는 이 PC(127.0.0.1)에서만 접속 가능하며 채팅을 저장하지 않음. 업로드 속도 측정과 새 버전 확인만 실행 시 외부 서버에 연결
공식 API 우선치지직과 YouTube는 공식 API 사용. 비공식 수신은 다른 채널 시험 용도
기존 프로그램 활용트래킹(VTube Studio, VSeeFace 등)과 송출(OBS Studio)은 기존 프로그램을 사용하고, 프로그램 간 설정과 연결을 담당
