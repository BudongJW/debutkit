설명

버튜버 방송 준비용 오픈소스 소프트웨어. 첫 방송 전에 필요한 PC 점검, OBS 장면 구성, 채팅창과 후원 알림 연결, 캐릭터 방송, 방송 중 자동 클립을 하나의 프로그램으로 제공합니다.

사용 대상

  • 첫 방송을 준비하는 개인 버튜버
  • 치지직, SOOP, Twitch, YouTube에 동시 송출하는 스트리머
  • 별도 아바타 프로그램 없이 PNGTuber나 3D 캐릭터로 방송하는 경우
  • OBS 장면과 오버레이를 처음 설정하는 경우
  • 기획사 소속 활동 예정으로 아바타 모델의 법인 사용 조건 확인이 필요한 경우

주요 기능

  • PC 점검 메모리, CPU, 그래픽카드, 저장 공간, 마이크, 웹캠, OBS, 트래킹 프로그램, ffmpeg 점검과 조치 안내. 업로드 속도 측정과 비트레이트 추천 doctor
  • OBS 장면 구성 대기 화면, 본방송, 토크, 자리 비움, 엔딩 장면 생성. 아바타 투명 배경 캡처, 채팅창과 후원 알림 연결, 기존 장면 유지 scenes
  • 채팅창과 후원 알림 치지직, SOOP, Twitch, YouTube 채팅을 OBS 브라우저 소스 하나에 표시. 후원, 구독, 슈퍼챗, 멤버십 알림. 채팅창 표시 형태 6종과 이름 색, 등장, 정렬. 알림 꾸미기(배치 6종, 위치 9곳, 문구, 효과음, 금액 구간별 그림과 효과) overlay
  • 시청자 참여 추첨 채팅에 !참가를 입력한 시청자(선택 시 후원자 포함)를 모아 당첨자를 뽑거나 순서를 정하고 방송 화면에 당첨 카드, 순서표로 표시 raffle
  • 채팅 명령 스트리머와 매니저가 채팅으로 캐릭터 동작, VTube Studio 단축키, 참여 추첨을 조작(!동작, !단축키, !모집, !추첨)
  • 후원 추첨 연출 후원이 오면 상품표에서 확률대로 뽑아 카드 뒤집기, 룰렛, 캡슐 뽑기, 즉석 복권, 티켓 출력, 추첨기, 타로로 표시. 금액별 추첨 횟수, 희귀 상품 강조, 대본 새 창, OBS 독용 조작 화면 draw
  • 뽑기판 칸을 눌러 여는 방송용 뽑기판. 당첨 칸은 조작 화면에서만 보이고 채팅 명령이나 후원으로 시청자가 열기(선택). 배치의 SHA-256 값을 먼저 공개하는 공정성 확인 pick
  • 후원 벽, 목표 게이지, 후원 순위 4개 플랫폼의 후원을 단위별 칸에 카드로 쌓는 방송 벽지. 시그니처 금액 그림, 오라 단계, 등장 연출 10종. 닉네임은 이 PC에만 저장 wall
  • 참여 레이스 참여 추첨 참가자가 겨루는 구슬 레이스, 달리기 경주, 서바이벌. 순위는 시작할 때 정해 모든 화면이 같은 결과 race
  • 방송 화면 미리보기, 방송 색, 방송 스타일 모든 방송 화면을 OBS 장면과 같은 자리에 겹쳐 보고 시험 후원으로 확인. 주 색과 강조 색 하나로 모든 화면의 색을 맞추고, 방송 스타일 16종(일반 8종과 게임 장르 8종)과 글꼴(설치한 글꼴, 내 글꼴 올리기)로 모양을 바꿈. 게임 패키지 10종(발로란트, 리그 오브 레전드, 오버워치, 하스스톤 등)은 그 게임의 HUD를 피한 배치와 프레임(캐릭터 테두리, 대기, 자리 비움, 엔딩 화면)까지 /stage
  • OBS에 넣기 시작하기 화면의 방송 준비 목록과 방송 화면마다 단추 하나로 OBS 장면에 넣기(크기, 자리, 알림 소리까지). 주소를 복사해 크기를 입력할 필요 없음
  • 디스코드 합방 디스코드 음성 위젯을 방송 스타일로 꾸미고 참여자별 캐릭터 그림으로, 웹훅 방송 알림
  • 팬 커뮤니티 트게더처럼 스트리머마다 자기 커뮤니티(공지, 방송 일정, 게시판, 팬아트, 출석과 포인트). 내 Cloudflare 무료 계정에 올리고 방송 채팅 !인증으로 가입, !출석, 방송에 띄우기 community
  • 캐릭터 PNGTuber, 3D(VRM, GLB, FBX), Live2D 등록과 사용 조건 확인. debutkit 캐릭터 화면으로 방송(마이크 음량으로 입 움직임, 눈 깜빡임, 웹캠 얼굴 추적). 기본 캐릭터 데비를 PNGTuber와 3D(VRM, CC0, 표정 18종) 두 가지로 포함 character
  • 방송 이미지 만들기 프사, 다시보기 썸네일, YouTube 채널 배너, Twitch 프로필 배너, SOOP 방송국 배너를 방송 색과 캐릭터 그림으로. 원형과 안전 영역 안내선, SOOP 배너는 200KB 이하 JPEG /decor
  • 캐릭터 그림 만들기 VRM을 이 PC에서 그려 표정 시트, PNGTuber 4상태, 포즈 그림(몸, 머리, 팔, 다리 조합, 랜덤, 투명 PNG). 모델 점검(표정, 텍스처 무게)과 텍스처를 줄인 가벼운 사본 /character/sheet
  • 방송 로고 만들기 함께 배포하는 아이콘(Fluent Emoji, Phosphor, MIT, 한국어 검색, 채널 색)과 기본 도형, 계정 없는 공개 모델 AI Horde, 공개 이미지 모델 Qwen-Image(ComfyUI 또는 Hugging Face) 또는 본인 API 키의 생성형 AI(Claude, OpenAI, Recraft) 심볼과 채널 이름(글꼴 윤곽선)으로 SVG, 투명 PNG 로고. 외곽선과 스티커 마감, 아이콘 출처와 AI 생성 표시, API 키 암호화 저장 logo
  • 휴대폰 앱 안드로이드, 아이폰 앞면 카메라로 얼굴 추적(MediaPipe, ARKit)해 표정 52개와 머리 움직임을 PC로 전송. 카메라 영상 모드는 WebRTC로 OBS에 직접 전송. QR 등록과 PC 승인. 안드로이드는 PC 없이 바로 방송(캐릭터 화면 또는 카메라 영상) mobile
  • 휴대폰 조작 화면 같은 Wi-Fi의 휴대폰 브라우저로 참여 추첨과 3D 캐릭터 동작 조작, 후원 추첨 결과 확인. QR 등록과 PC 승인, 요청 서명 remote
  • 휴대폰 카메라 영상 휴대폰 카메라 영상(실사, 손 캠)을 같은 Wi-Fi로 받는 OBS 소스. 암호 연결, Larix Broadcaster QR 가져오기 camera
  • OBS 없이 바로 방송 캐릭터, 채팅, 후원 알림, 추첨 연출을 모은 송출 화면을 치지직, SOOP, YouTube, Twitch로 바로 송출. 하드웨어 H.264, 스트림 키 암호화 저장. Windows, 토크 방송용 broadcast
  • 휴대폰 얼굴 추적 아이폰 앱(iFacialMocap, VTube Studio)의 ARKit 표정 52개와 머리 움직임을 같은 Wi-Fi로 받아 캐릭터에 반영. 퍼펙트 싱크 모델은 얼굴 전체가 움직임 phone
  • 3D 캐릭터 동작 VRMA, Mixamo 등의 FBX, GLB 동작 등록. 대기 중 반복하는 기본 동작과 후원 반응 motion
  • VTube Studio 연동 Live2D 모델 보내기와 불러오기, 후원 시 단축키 실행. VRM은 Warudo로 보내기 vts
  • 방송 중 자동 클립 채팅이 평소보다 크게 증가하거나 스트리머, 매니저가 !clip을 입력하면 OBS 리플레이 버퍼를 클립으로 저장. 동시 송출 시 전 플랫폼 채팅 합산. 클립마다 움짤과 세로 쇼츠(선택) overlay --clip, clip
  • 방송 시작 버튼 방송에 필요한 프로그램, 폴더, 사이트를 차례로 켜고 메신저, 게임 런처는 먼저 끔. 창 자리 기억(듀얼 모니터), 방송 끝에 꺼 둔 프로그램 다시 켜기 launch
  • VMC 송신 debutkit 얼굴 추적 값(웹캠, 휴대폰, 표정 52개)을 Warudo, VSeeFace, VMagicMirror로 vmc
  • 공식 API 연동 치지직 Open API 로그인(본인 채널의 채팅, 후원, 구독), YouTube Data API 라이브 채팅 chzzk login

설정 마법사에서 모든 기능을 사용할 수 있으며, 같은 기능을 명령줄로도 제공합니다.

이용 환경

  • Windows 64비트(Windows 11에서 검증), macOS 11 이상(Apple Silicon), Linux x64(Ubuntu 22.04 이상 기준)
  • OBS Studio 28 이상. 장면 생성과 자동 클립에는 OBS WebSocket 서버 사용 설정 필요
  • 관리자 권한과 파이썬 불필요. 자동 클립용 ffmpeg는 설치 과정이나 설정 마법사에서 다운로드
  • 설정 마법사, 명령줄, 오버레이 화면 모두 한국어

가격

  • 무료. 모든 기능을 Apache-2.0으로 공개
  • 소속 프로그램 참여 여부와 무관하게 같은 기능 제공(참여 안내)

데비와 함께 보는 debutkit

  • 데비: 첫 방송을 준비하는 신인 버튜버. debutkit 기본 캐릭터(PNGTuber, 3D VRM)이자 화면 곳곳의 안내 역할
  • 아래 그림의 데비는 함께 배포하는 기본 3D 캐릭터를 캐릭터 그림 만들기의 추천 자세로 그린 것. 화면은 실제 debutkit 화면

설치

배포 형태Windows 설치 프로그램(setup.exe)과 압축 파일(zip), macOS 앱(debutkit.app), Linux 압축 파일(tar.gz). 설정 마법사와 명령줄 도구 포함
설치 방식현재 사용자 계정에 설치, 시작 메뉴 등록. 관리자 권한과 파이썬 불필요
선택 구성 요소ffmpeg(자동 클립용). 설치 과정 또는 설정 마법사에서 다운로드
코드 서명Windows 미적용(SmartScreen 경고가 표시될 수 있음). macOS 임시 서명, 공증 미적용(첫 실행 시 Gatekeeper 경고). 코드 서명 정책
파이썬 패키지모든 운영체제에서 사용 가능. Python 3.10 이상

설치 절차(Windows)

  1. 릴리스 페이지에서 debutkit-버전-windows-x64-setup.exe 다운로드
  2. 설치 프로그램 실행. 자동 클립을 사용할 경우 ffmpeg 다운로드 선택
  3. 시작 메뉴에서 debutkit 실행
  4. 설정 마법사의 단계별 안내에 따라 진행

설치 없이 사용하려면 debutkit-버전-windows-x64.zip의 압축을 해제한 뒤 debutkit-gui.exe를 실행합니다. macOS와 Linux 설치 방법은 사용 설명서에 있습니다.

pip install "debutkit[gui] @ git+https://github.com/BudongJW/debutkit"

운영 원칙

무상 공개모든 기능을 Apache-2.0으로 공개. 소속 프로그램 참여 여부와 무관
정보 수집 없음사용 통계 미전송. 오버레이는 이 PC(127.0.0.1)에서만 접속 가능하며 채팅을 저장하지 않음. 업로드 속도 측정과 새 버전 확인만 실행 시 외부 서버에 연결
공식 API 우선치지직과 YouTube는 공식 API 사용. 비공식 수신은 다른 채널 시험 용도
기존 프로그램 활용트래킹(VTube Studio, VSeeFace 등)과 송출(OBS Studio)은 기존 프로그램을 사용하고, 프로그램 간 설정과 연결을 담당
