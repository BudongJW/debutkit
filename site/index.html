설명 설치 운영 원칙 릴리스

설명

버튜버 방송 준비용 오픈소스 소프트웨어. 첫 방송 전에 필요한 PC 점검, OBS 장면 구성, 채팅창과 후원 알림 연결, 캐릭터 방송, 방송 중 자동 클립을 하나의 프로그램으로 제공합니다.

사용 대상

  • 첫 방송을 준비하는 개인 버튜버
  • 치지직, SOOP, Twitch, YouTube에 동시 송출하는 스트리머
  • 별도 아바타 프로그램 없이 PNGTuber나 3D 캐릭터로 방송하는 경우
  • OBS 장면과 오버레이를 처음 설정하는 경우
  • 기획사 소속 활동 예정으로 아바타 모델의 법인 사용 조건 확인이 필요한 경우

주요 기능

  • PC 점검 메모리, CPU, 그래픽카드, 저장 공간, 마이크, 웹캠, OBS, 트래킹 프로그램, ffmpeg 점검과 조치 안내. 업로드 속도 측정과 비트레이트 추천 doctor
  • OBS 장면 구성 대기 화면, 본방송, 토크, 자리 비움, 엔딩 장면 생성. 아바타 투명 배경 캡처, 채팅창과 후원 알림 연결, 기존 장면 유지 scenes
  • 채팅창과 후원 알림 치지직, SOOP, Twitch, YouTube 채팅을 OBS 브라우저 소스 하나에 표시. 후원, 구독, 슈퍼챗, 멤버십 알림. 표시 형태 5종 overlay
  • 후원 추첨 연출 후원이 오면 상품표에서 확률대로 뽑아 카드 뒤집기나 룰렛으로 표시. 금액별 추첨 횟수, 희귀 상품 강조, 최근 결과와 읽을 문장, OBS 독용 조작 화면 draw
  • 캐릭터 PNGTuber, 3D(VRM, GLB, FBX), Live2D 등록과 사용 조건 확인. debutkit 캐릭터 화면으로 방송(마이크 음량으로 입 움직임, 눈 깜빡임, 웹캠 얼굴 추적). 기본 캐릭터 포함 character
  • 3D 캐릭터 동작 VRMA, Mixamo 등의 FBX, GLB 동작 등록. 대기 중 반복하는 기본 동작과 후원 반응 motion
  • VTube Studio 연동 Live2D 모델 보내기와 불러오기, 후원 시 단축키 실행. VRM은 Warudo로 보내기 vts
  • 방송 중 자동 클립 채팅이 평소보다 크게 증가하거나 스트리머, 매니저가 !clip을 입력하면 OBS 리플레이 버퍼를 클립으로 저장. 동시 송출 시 전 플랫폼 채팅 합산 overlay --clip
  • 공식 API 연동 치지직 Open API 로그인(본인 채널의 채팅, 후원, 구독), YouTube Data API 라이브 채팅 chzzk login

설정 마법사에서 모든 기능을 사용할 수 있으며, 같은 기능을 명령줄로도 제공합니다.

이용 환경

  • Windows 64비트(Windows 11에서 검증), macOS 11 이상(Apple Silicon), Linux x64(Ubuntu 22.04 이상 기준)
  • OBS Studio 28 이상. 장면 생성과 자동 클립에는 OBS WebSocket 서버 사용 설정 필요
  • 관리자 권한과 파이썬 불필요. 자동 클립용 ffmpeg는 설치 과정이나 설정 마법사에서 다운로드
  • 설정 마법사, 명령줄, 오버레이 화면 모두 한국어

가격

  • 무료. 모든 기능을 Apache-2.0으로 공개
  • 소속 프로그램 참여 여부와 무관하게 같은 기능 제공(참여 안내)

설치

배포 형태Windows 설치 프로그램(setup.exe)과 압축 파일(zip), macOS 앱(debutkit.app), Linux 압축 파일(tar.gz). 설정 마법사와 명령줄 도구 포함
설치 방식현재 사용자 계정에 설치, 시작 메뉴 등록. 관리자 권한과 파이썬 불필요
선택 구성 요소ffmpeg(자동 클립용). 설치 과정 또는 설정 마법사에서 다운로드
코드 서명Windows 미적용(SmartScreen 경고가 표시될 수 있음). macOS 임시 서명, 공증 미적용(첫 실행 시 Gatekeeper 경고). 코드 서명 정책
파이썬 패키지모든 운영체제에서 사용 가능. Python 3.10 이상

설치 절차(Windows)

  1. 릴리스 페이지에서 debutkit-버전-windows-x64-setup.exe 다운로드
  2. 설치 프로그램 실행. 자동 클립을 사용할 경우 ffmpeg 다운로드 선택
  3. 시작 메뉴에서 debutkit 실행
  4. 설정 마법사의 단계별 안내에 따라 진행

설치 없이 사용하려면 debutkit-버전-windows-x64.zip의 압축을 해제한 뒤 debutkit-gui.exe를 실행합니다. macOS와 Linux 설치 방법은 사용 설명서에 있습니다.

파이썬 패키지

pip install "debutkit[gui] @ git+https://github.com/BudongJW/debutkit"
debutkit-gui

운영 원칙

무상 공개모든 기능을 Apache-2.0으로 공개. 소속 프로그램 참여 여부와 무관
정보 수집 없음사용 통계 미전송. 오버레이는 이 PC(127.0.0.1)에서만 접속 가능하며 채팅을 저장하지 않음. 업로드 속도 측정과 새 버전 확인만 실행 시 외부 서버에 연결
공식 API 우선치지직과 YouTube는 공식 API 사용. 비공식 수신은 다른 채널 시험 용도
기존 프로그램 활용트래킹(VTube Studio, VSeeFace 등)과 송출(OBS Studio)은 기존 프로그램을 사용하고, 프로그램 간 설정과 연결을 담당
