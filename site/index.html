소개

버튜버 방송 준비용 오픈소스 소프트웨어. 첫 방송 전 준비, 방송 중 연출, 방송 밖 콘텐츠 제작을 프로그램 하나로 제공

  • 4개지원 방송 플랫폼치지직, SOOP, Twitch, YouTube
  • 5단계설정 마법사PC 점검부터 OBS 장면까지
  • 12종방송 이미지 규격프사, 썸네일, 배너, 쇼츠 커버
  • 0원이용 요금모든 기능 공개, Apache-2.0

개발 배경

  • 신규 버튜버의 첫 방송 준비 항목: PC 사양 확인, OBS 장면 구성, 플랫폼별 채팅창과 후원 알림 연결, 캐릭터 준비, 방송 이미지 제작
  • 기존 방식: 항목마다 다른 사이트와 프로그램 이용. 설정 값의 적정 여부 판단 기준 부재
  • debutkit 방식: 설정 마법사의 순서대로 준비 항목 처리. 방송 중 연출과 방송 이미지 제작을 같은 방송 색과 글꼴로 연결

이용 대상

  • 첫 방송을 준비하는 개인 버튜버
  • 치지직, SOOP, Twitch, YouTube에 동시 송출하는 스트리머
  • 별도 아바타 프로그램 없이 PNGTuber나 3D 캐릭터로 방송하는 스트리머
  • OBS 장면과 오버레이를 처음 설정하는 스트리머
  • 기획사 소속 활동 예정으로 아바타 모델의 법인 사용 조건 확인이 필요한 버튜버

POINT 1

방송 준비

  • 설정 마법사 5단계: PC 점검, 캐릭터, OBS 장면, 채팅과 알림, 마무리
  • 시작하기 화면의 방송 준비 목록과 방송 직전 점검
  • 방송 화면마다 OBS에 넣기 단추

POINT 2

방송 진행

  • 4개 플랫폼 채팅과 후원 알림을 한 화면에 표시
  • 캐릭터 화면: 입 움직임, 눈 깜빡임, 얼굴 추적
  • 채팅 급증 구간 자동 클립

POINT 3

방송 연출

  • 후원 추첨 연출 7종과 연출 모양 32종
  • 시청자 참여 추첨, 참여 레이스 4종, 주사위 판, 뽑기판
  • 모든 연출에 같은 방송 색과 글꼴 적용

소개 그림: 함께 배포하는 기본 3D 캐릭터 데비를 캐릭터 그림 만들기의 추천 자세로 그려 실제 debutkit 화면과 합성

기능

그림: 예시 이름과 기본 설정의 실제 debutkit 화면(packaging/build_screens.py로 촬영)

FEATURE 01

PC 점검과 설정 마법사

방송 전 PC 상태와 연결 항목의 단계별 점검 doctor

  • 설정 마법사 5단계: PC 점검, 캐릭터, OBS 장면, 채팅과 알림, 마무리
  • 점검 항목: 메모리, CPU, 그래픽카드, 저장 공간, 마이크, 웹캠, OBS, 트래킹 프로그램, ffmpeg
  • 항목별 조치 안내. 업로드 속도 측정과 송출 비트레이트 추천
  • 점검 결과 복사: 문제 제보와 실사용 환경 검증에 그대로 첨부

FEATURE 02

OBS 장면 구성과 방송 화면 미리보기

OBS 장면 생성과 방송 화면 배치 확인 scenes

  • 장면 5종 생성: 대기 화면, 본방송, 토크, 자리 비움, 엔딩. 기존 장면 유지
  • OBS에 넣기: 방송 화면마다 단추 하나로 장면에 추가(크기, 위치, 알림 소리 포함). 주소 복사와 크기 입력 불필요
  • 방송 화면 미리보기: 모든 방송 화면을 OBS 장면과 같은 위치에 겹쳐 확인. 시험 후원으로 알림과 연출 확인
  • 방송 색: 주 색과 강조 색으로 모든 방송 화면의 색 통일. 추천 조합 6종

FEATURE 03

통합 채팅창과 후원 알림

4개 플랫폼의 채팅과 후원을 OBS 브라우저 소스 하나로 표시 overlay

  • 치지직, SOOP, Twitch, YouTube 채팅 동시 표시. 플랫폼 표시와 매니저, 스트리머 표시
  • 채팅창 표시 형태 6종, 이름 색, 등장 효과, 정렬 방향
  • 후원, 구독, 슈퍼챗, 멤버십 알림. 알림 꾸미기(배치 6종, 위치 9곳, 문구, 효과음, 금액 구간별 그림과 효과)
  • 치지직 Open API, YouTube Data API 공식 연동

FEATURE 04

캐릭터 방송

별도 아바타 프로그램 없이 캐릭터 화면으로 방송 character

  • PNGTuber, 3D(VRM, GLB, FBX), Live2D 등록과 사용 조건 확인(방송, 수익 방송, 소속사 활동)
  • 마이크 음량 입 움직임, 눈 깜빡임, 웹캠 얼굴 추적, 휴대폰 얼굴 추적(표정 52개)
  • 3D 캐릭터 동작: VRMA, Mixamo FBX, GLB 동작 등록. 대기 동작과 후원 반응
  • 기본 캐릭터 데비: 첫 방송을 준비하는 신인 버튜버 설정의 debutkit 캐릭터. 3D 데비는 CC0 VRoid 샘플의 색을 바꾼 모델로 방송, 수익 방송, 수정 가능

FEATURE 05

후원 추첨 연출

후원 금액에 따라 상품표의 확률대로 추첨하고 방송 화면에 결과 연출 draw

  • 연출 7종: 카드 뒤집기, 룰렛, 캡슐 뽑기, 즉석 복권, 티켓 출력, 추첨기, 타로
  • 연출 모양 32종. 희귀 상품 강조, 금액별 추첨 횟수
  • 대본 새 창, OBS 독용 조작 화면, 추첨 기록

FEATURE 06

시청자 참여 추첨

채팅 명령으로 참가자를 모집하고 당첨자와 순서 결정 raffle

  • 채팅에 !참가를 입력한 시청자 모집(선택 시 후원자 포함)
  • 당첨자 추첨과 순서 정하기. 방송 화면의 당첨 카드와 순서표
  • 후원 뒤 한마디: 후원 참가자가 5분 안에 처음 쓴 채팅을 당첨 카드 말풍선으로 표시
  • 매니저 채팅 명령(!모집, !추첨)과 휴대폰 조작 화면

FEATURE 07

참여 레이스

참여 추첨 참가자가 함께 달리는 경주 게임 race

  • 게임 4종: 구슬 레이스(코스 4종), 달리기 경주, 수영(8레인), 서바이벌
  • 참가 인원 100명까지. 달리기와 수영은 8명씩 조별 경기 뒤 결승 또는 30명까지 함께
  • 깜짝 요소(바람, 스퍼트, 가시 함정 등)와 실시간 순위
  • 순위는 시작 시 결정. 모든 방송 화면에 같은 결과

FEATURE 08

주사위 판

참가자가 주사위를 굴려 칸의 미션을 수행하는 말판 게임 /board

  • 참가자 8명까지. 정사각형 둘레 16~28칸
  • 특별한 칸(한 번 더, 뒤로 2칸, 한 번 쉬기)과 행운 카드 6종
  • 칸 미션 직접 작성(비우면 기본 미션), 디자인 3종
  • 차례인 시청자의 채팅 굴리기(기본 !주사위). 주사위는 이 PC의 운영체제 난수

FEATURE 09

뽑기판

칸을 눌러 여는 방송용 뽑기판 pick

  • 디자인 8종(카드, 긁는 복권, 봉투, 캡슐, 작은 문, 스티커, 메모지, 풍선 터뜨리기), 칸 덮개 18종
  • 당첨 칸은 조작 화면에서만 표시. 채팅 명령이나 후원으로 시청자 열기(선택)
  • 공정성 확인: 배치의 SHA-256 값을 먼저 공개

FEATURE 10

후원 벽, 목표 게이지, 후원 순위

4개 플랫폼의 후원을 단위별 칸에 카드로 쌓는 방송 벽지 wall

  • 후원 단위별 칸(별풍선 개수, 후원 금액대)과 카드 등장 연출 10종
  • 시그니처 금액 그림, 오라 단계, 목표 게이지, 후원 순위
  • 닉네임은 이 PC에만 저장

FEATURE 11

방송 스타일과 게임 패키지

방송 화면 전체의 모양과 게임 방송 배치 /stage

  • 방송 스타일 16종(파스텔, 네온, 레트로 픽셀, 유리 등 일반 8종과 게임 장르 8종)
  • 게임 패키지 10종(발로란트, 리그 오브 레전드, 오버워치, 하스스톤 등): 게임 HUD를 피한 배치와 프레임(캐릭터 테두리, 대기, 자리 비움, 엔딩 화면)
  • 공통 글꼴: 함께 배포하는 한글 글꼴 18종(SIL OFL), 이 PC 기본 글꼴, 내 글꼴 올리기

FEATURE 12

방송 이미지 만들기

방송 색과 캐릭터 그림으로 플랫폼 규격 이미지 제작 /decor

  • 그림 종류 12종: 프사, 다시보기 썸네일, YouTube 채널 배너, Twitch 프로필 배너, SOOP 방송국 배너와 연결 배너, 쇼츠 커버, 체키, 네컷 사진, 방셀 꾸미기, 시그니처 풍선 그림, 원하는 크기
  • 완성 프리셋 9종, 테두리, 파티클, 자막 스타일, 손그림 펜
  • 모든 그림 종류의 움짤(GIF, WebP) 저장. 안전 영역 안내선
  • 시그니처 풍선 그림은 후원 벽에 바로 등록

FEATURE 13

캐릭터 그림 만들기

VRM 캐릭터를 이 PC에서 그려 방송용 그림 제작 /character/sheet

  • 표정 시트, PNGTuber 4상태, 포즈 그림(투명 PNG)
  • 포즈 그림: 부위 8개와 선택지 76개, 손 모양 8종, 추천 자세 10종, 관절 직접 조정
  • 자세 파일 불러오기(VRMA, MMD VPD, 자세 JSON), VMC로 자세 전송(Warudo, VSeeFace, VMagicMirror)
  • 모델 점검(표정, 텍스처 용량)과 텍스처를 줄인 경량 사본

그 밖의 기능

  • 방송 중 자동 클립채팅 급증 또는 !clip 입력 시 OBS 리플레이 버퍼를 클립으로 저장. 움짤과 세로 쇼츠(선택)
  • 방송 시작 버튼방송에 필요한 프로그램, 폴더, 사이트를 차례로 실행. 메신저와 게임 런처 종료, 방송 후 다시 실행
  • OBS 없이 바로 방송캐릭터, 채팅, 후원 알림, 추첨 연출을 모은 송출 화면을 플랫폼으로 직접 송출(Windows, 토크 방송용)
  • 휴대폰 앱안드로이드, 아이폰 얼굴 추적(표정 52개). 카메라 영상 전송. 안드로이드는 PC 없이 바로 방송
  • 휴대폰 조작 화면같은 Wi-Fi의 휴대폰 브라우저로 참여 추첨과 3D 캐릭터 동작 조작. QR 등록과 PC 승인
  • 방송 로고 만들기함께 배포하는 아이콘, 기본 도형, 공개 이미지 모델 또는 본인 API 키의 생성형 AI 심볼과 채널 이름으로 SVG, 투명 PNG 로고
  • 팬 커뮤니티공지, 방송 일정, 게시판, 팬아트, 출석과 포인트. 본인 Cloudflare 무료 계정에 게시
  • 디스코드 합방디스코드 음성 위젯(StreamKit)의 방송 스타일 꾸미기와 참여자별 캐릭터 그림. 웹훅 방송 알림
  • VTube Studio 연동Live2D 모델 보내기와 불러오기, 후원 시 단축키 실행. VRM은 Warudo로 보내기

  2. 설치 프로그램 실행. 자동 클립 이용 시 ffmpeg 다운로드 선택
  3. 시작 메뉴에서 debutkit 실행
  4. 설정 마법사의 단계별 안내대로 진행

압축 파일 이용(별도 설치 불필요): debutkit-버전-windows-x64.zip 압축 해제 후 debutkit-gui.exe 실행. macOS와 Linux 설치 방법: 사용 설명서

파이썬 패키지

pip install "debutkit[gui] @ git+https://github.com/BudongJW/debutkit"
debutkit-gui

운영 원칙

무상 공개모든 기능을 Apache-2.0으로 공개. 소속 프로그램 참여 여부와 무관
정보 수집 없음이용 통계 미전송. 오버레이는 이 PC(127.0.0.1)에서만 접속 가능, 채팅 저장 없음. 외부 서버 연결은 업로드 속도 측정과 새 버전 확인 실행 시에만
공식 API 우선치지직과 YouTube는 공식 API 사용. 비공식 수신은 다른 채널 시험 용도
기존 프로그램 활용트래킹(VTube Studio, VSeeFace 등)과 송출(OBS Studio)은 기존 프로그램 이용. debutkit은 프로그램 간 설정과 연결 담당
