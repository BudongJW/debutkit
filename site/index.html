다운로드

배포 형태Windows용 압축 파일(zip). 설정 마법사 debutkit-gui.exe, 명령줄 도구 debutkit.exe 포함
지원 환경Windows 64비트. Windows 11에서 검증
필요 프로그램OBS Studio 28 이상(WebSocket 원격 제어 내장)
선택 프로그램ffmpeg(자동 클립). 설정 마법사 PC 점검 화면에서 내려받기
설치 방식압축 해제 후 실행. 관리자 권한, 파이썬 불필요
코드 서명미적용. Windows SmartScreen 경고 표시 가능
기타 운영체제macOS, Linux는 파이썬 패키지로 설치. Python 3.10 이상

설치 절차

  1. 릴리스 페이지에서 debutkit-버전-windows-x64.zip 다운로드
  2. 압축 해제
  3. debutkit-gui.exe 실행
  4. 마법사 순서대로 진행

파이썬 패키지 설치

pip install "debutkit[gui] @ git+https://github.com/BudongJW/debutkit"

주요 기능

설정 마법사debutkit-gui
  • 명령줄 없이 PC 점검부터 오버레이 실행까지 5단계 안내
  • ffmpeg 내려받기, 치지직 로그인을 창 안에서 처리
PC 점검debutkit doctor
  • 메모리, CPU, 그래픽카드, 저장 공간, 마이크, 웹캠, OBS와 원격 제어, 트래킹 프로그램, ffmpeg 점검
  • 항목별 해결 방법 표시. 설치나 설정 변경 없음
  • VRM 모델의 수익화, 법인(기획사) 사용 허락 확인
OBS 장면 세트debutkit scenes
  • 대기 화면, 본방송, 토크, 자리 비움, 엔딩 장면 자동 생성
  • 아바타 투명 배경 캡처, 채팅창과 후원 알림 연결
  • 기존 장면 유지. 자동 클립용 리플레이 버퍼 설정
통합 채팅창과 후원 알림debutkit overlay
  • 치지직, SOOP, Twitch 채팅을 OBS 브라우저 소스 한 화면에 표시
  • 후원, 구독 알림. 테마, 글자 크기, 줄 수, 사라짐 시간 조절
  • 방송 없이 데모 채팅과 테스트 버튼으로 모양 확인
방송 중 자동 클립overlay --clip
  • 채팅이 방송별 평소 수준보다 크게 몰리면 OBS 리플레이 버퍼를 클립으로 저장
  • 방장, 매니저의 !clip 명령으로 즉시 저장
  • 동시 송출 시 모든 플랫폼 채팅 합산
치지직 공식 APIdebutkit chzzk login
  • 내 채널의 채팅, 후원, 구독을 공식 Open API로 수신
  • 토큰은 이 PC 사용자 설정 폴더에 보관, 만료 시 자동 갱신

원칙

조건 없는 오픈소스모든 기능 무료 공개. 소속사 프로그램 참여 여부와 무관
수집 없음사용 통계 전송 없음. 오버레이는 이 PC(127.0.0.1)에서만 열림. 채팅 저장 없음
공식 경로 우선치지직은 공식 Open API 우선. 시청자 읽기는 다른 채널 시험용
연결 중심트래킹(VTube Studio, VSeeFace 등)과 송출(OBS)은 기존 프로그램 사용. 키트는 그 사이 연결
