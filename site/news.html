1.0.0rc1

2026-11-22, 사전 릴리스(1.0 후보)

기능은 1.0 기준으로 완료했습니다. 개발 환경에서 확인할 수 없는 항목을 실제 PC와 방송 계정으로 확인하기 위한 버전입니다. 확인 방법은 실제 환경 확인을 참고합니다.

추가

  • 실제 환경 확인 참여 안내와 보고 양식
  • 설정 마법사의 문제 제보 영역: 점검 결과 복사, 제보 양식 열기, 기록 폴더 열기
  • 오류 기록. 이 PC에만 저장하며 채팅 내용은 기록하지 않음
  • Linux에서 alsa-utils 없이도 마이크 감지

검증 범위

  • 확인: Linux 커널 가상 카메라 감지(arecord 유무 모두), 1.0 후보 버전의 Windows, macOS, Linux 빌드와 실행, 3개 운영체제 실제 OBS 검증
  • 미확인: 1.0 기준의 실제 계정, 실제 장치 항목(개발 계획)

0.6.0

2026-11-22

추가

  • macOS(Apple Silicon)용 debutkit.app과 Linux(x64)용 실행 파일. 파이썬 설치 없이 사용
  • YouTube 채팅 스트리밍 수신. 연결 1회에 5 단위만 사용해 할당량 부담을 줄이고 지연 감소. 사용할 수 없으면 요청 방식으로 자동 전환
  • 실제 OBS 검증 자동화. Linux의 실제 OBS로 장면 생성, 고급 출력 모드 리플레이 버퍼 설정, 스트리머 !clip 입력에 따른 클립 저장까지 릴리스마다 확인
  • 코드 서명 준비. 인증서를 등록하면 릴리스 빌드가 자동으로 서명

변경

  • 창 캡처 소스가 없는 OBS에서 아바타 소스를 생략할 때 안내 표시
  • 쓰지 않는 Qt 라이브러리를 제외해 실행 파일 크기 축소

검증 범위

  • 확인: Linux 실제 OBS 32.2의 장면 생성과 자동 클립 저장(10.7초 클립), 고급 출력 모드 리플레이 버퍼 설정, 설치 프로그램의 ffmpeg 실제 다운로드, macOS와 Linux 실행 파일의 실행
  • 미확인: 실제 YouTube 서버와 API 키를 사용한 스트리밍 수신, Linux 아바타 창 캡처, macOS의 실제 OBS 장면 구성

0.1.0

2026-11-21

배경

  • 신규 버튜버의 준비 과정에서 어려움이 집중되는 단계는 아바타 제작 이후의 설정 작업(OBS 투명 배경, 치지직과 SOOP 채팅 통합, 후원 알림, PC 사양 확인)
  • 개별 방법은 공개되어 있으나 여러 프로그램과 설정을 각각 익혀야 하는 부담이 있음

최초 공개 기능

  • PC 점검(debutkit doctor). 메모리, CPU, 그래픽카드, 저장 공간, OBS와 원격 제어, 트래킹 프로그램 점검. VRM 모델의 수익화, 기획사(법인) 사용 허락 확인
  • OBS 장면 구성(debutkit scenes). 대기 화면, 본방송, 토크, 자리 비움, 엔딩 장면 생성. 아바타 투명 배경 캡처, 채팅창과 후원 알림 연결
  • 통합 채팅창과 후원 알림(debutkit overlay). 치지직, SOOP, Twitch 채팅 통합 표시. 본인 치지직 채널은 공식 Open API 사용

오픈소스로 공개하는 이유

  • 트래킹 프로그램과 해외 플랫폼용 채팅 오버레이는 이미 다수 존재
  • 치지직, SOOP을 우선 지원하면서 데뷔 전 점검부터 방송 중 클립까지 연결하는 도구는 없음
  • 기존 프로그램(OBS, VTube Studio, VSeeFace)은 그대로 사용하고 연결 부분만 공개
