1.0.0rc15

2026-11-23, 사전 릴리스(1.0 후보 15차)

추가

  • 휴대폰 앱 카메라 영상 모드: 휴대폰 카메라 영상(앞면, 뒷면)을 WebRTC로 OBS 브라우저 소스에 직접 전송. 외부 서버 없음, 소리는 PC 마이크
  • OBS 소스 [DK] 휴대폰 카메라(앱)와 수신 화면(/camera/view), 휴대폰 연결 화면의 앱 영상용 OBS 소스 만들기, debutkit camera setup --app
  • 연결이 끊기면 자동으로 다시 연결, 처음 연결한 수신 화면만 영상을 받음

검증 범위

  • 확인: 연결 중계 단위 테스트, 브라우저 두 탭 연결과 영상 디코딩, 안드로이드 에뮬레이터 디버그와 배포 빌드에서 수신 화면 영상 디코딩, 수신 화면 새로 고침 후 자동 다시 연결. iOS는 CI 빌드와 시뮬레이터 테스트
  • 미확인: 실제 휴대폰과 OBS에서의 지연과 화질, 공유기 환경별 연결, 장시간 발열

1.0.0rc14

2026-11-23, 사전 릴리스(1.0 후보 14차)

추가

  • debutkit 휴대폰 앱: 휴대폰 앞면 카메라로 얼굴을 추적해 머리 움직임과 표정 52개를 같은 Wi-Fi의 PC로 전송. 안드로이드(MediaPipe)는 릴리스에 APK 첨부, 아이폰(ARKit)은 Mac과 Xcode로 직접 빌드
  • 등록과 보안: 휴대폰 조작 화면과 같은 QR 코드와 PC 승인, 값마다 기기 비밀값으로 서명, PC는 승인한 기기의 새로운 값만 사용
  • 화면 어둡게, 추적 중 화면 꺼짐 방지, 발열 시 전송 횟수 줄임, PC에서 삭제하면 등록 화면으로

검증 범위

  • 확인: PC 수신 단위 테스트, 안드로이드와 iOS 단위 테스트(서명과 패킷이 PC와 같음). 안드로이드 에뮬레이터에서 등록, 승인, 시험 이미지 추적, PC의 서명된 값 수신(표정 52개), 삭제 후 등록 화면 복귀, 배포 빌드 카메라 추적 실행. iOS는 CI에서 시뮬레이터 테스트와 기기용 빌드
  • 미확인: 실제 휴대폰의 전면 카메라 추적(안드로이드), ARKit 추적과 머리 회전 방향(아이폰), 장시간 발열. 안드로이드 APK는 시험용 서명

1.0.0rc13

추가

  • 휴대폰 연결 화면의 조작 화면 영역(켜기, QR, 승인, 삭제), debutkit remote 명령, 설정 마법사 버튼

검증 범위

  • 확인: 단위 테스트(등록과 승인, 만료, 최대 기기 수, 서명과 본문 변경, 재사용, 시각 차이, 실패 차단, 다른 주소와 다른 사이트 요청 거부, 조작, 삭제, 서버 관리 경로, 명령줄, 설정 마법사). 휴대폰 화면의 서명 계산이 서버와 같음(Node). 브라우저에서 등록, 승인, 모집, 뽑기, 삭제까지 전체 흐름
  • 미확인: 실제 휴대폰(아이폰 Safari, 안드로이드 Chrome)과 Windows 방화벽 안내

  • 통합 채팅창과 후원 알림(debutkit overlay). 치지직, SOOP, Twitch 채팅 통합 표시. 본인 치지직 채널은 공식 Open API 사용

오픈소스로 공개하는 이유

  • 트래킹 프로그램과 해외 플랫폼용 채팅 오버레이는 이미 다수 존재
  • 치지직, SOOP을 우선 지원하면서 데뷔 전 점검부터 방송 중 클립까지 연결하는 도구는 없음
  • 기존 프로그램(OBS, VTube Studio, VSeeFace)은 그대로 사용하고 연결 부분만 공개
