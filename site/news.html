debutkit 0.5: YouTube 채팅, 업로드 속도 측정, 설치 프로그램

추가

  • YouTube 라이브 채팅: 공식 YouTube Data API(API 키). 채팅, 슈퍼챗, 슈퍼스티커, 멤버십 알림. 치지직, SOOP, Twitch와 한 화면에 표시, 자동 클립 판단에도 합산
  • 업로드 속도 측정: debutkit doctor --speed, 설정 마법사 PC 점검 화면 버튼. 측정값으로 해상도와 영상 비트레이트 추천
  • 채팅창 테마 3종: 카드(이름 줄 분리), 외곽선 글자, 밝은 말풍선
  • 오버레이 설정 화면의 채팅창 모양 선택: 테마, 글자 크기, 줄 수, 사라짐, 플랫폼 표시를 고르면 OBS용 주소에 반영
  • Windows 설치 프로그램: 관리자 권한 없이 설치, 시작 메뉴 바로 가기, ffmpeg 내려받기 선택

참고

  • YouTube API 기본 할당량: 하루 약 5시간 방송분(요청 간격 10초 기준). 긴 방송은 간격 조정
  • 업로드 속도 측정과 새 버전 확인만 외부 서버에 연결. 둘 다 직접 실행할 때만

확인 범위

  • 확인 완료: 업로드 속도 실제 측정, 테마 화면, 설치 프로그램의 설치, 실행, 제거(릴리스 빌드)
  • 미확인: 실제 YouTube 방송과 API 키로 채팅 수신

debutkit 0.4: 마이크와 웹캠 점검, 새 버전 확인

추가

  • PC 점검 마이크 항목: 사용 중인 입력 장치 확인. 없으면 필요 표시(꺼진 장치, 분리된 장치 제외)
  • PC 점검 웹캠 항목: 연결된 카메라 확인. 없으면 주의 표시(아이폰 얼굴 트래킹, PNGTuber는 불필요)
  • 새 버전 확인: debutkit setup --check-update, 설정 마법사 마무리 단계 버튼. 직접 실행할 때만 GitHub 연결
  • GitHub 이슈 양식: 문제 제보(doctor --json 결과 칸), 기능 제안

확인 범위

  • 확인 완료: Windows PC의 마이크, 웹캠 인식, GitHub 최신 릴리스 조회
  • 미확인: macOS, Linux의 마이크, 웹캠 인식

debutkit 0.3: 외부 명령 없이 준비 완료

목표

  • 자동 클립, 치지직 공식 API 준비 과정에서 다른 프로그램의 명령 입력 제거
  • 방송 중 실패하던 상황을 시작 전에 확인

추가

  • debutkit setup --ffmpeg: ffmpeg 내려받기(Windows, SHA-256 확인)
  • 설정 마법사 PC 점검 화면의 ffmpeg 내려받기 버튼, 완료 후 자동 재점검
  • debutkit chzzk login, logout: 치지직 공식 API 로그인
  • 설정 마법사 치지직 API 칸(Client ID, Client Secret)과 로그인 버튼
  • 오버레이 설정 화면의 방장 !clip 테스트 버튼
  • 마무리 단계의 자동 클립 저장 폴더 열기
  • 프로젝트 사이트 개설: 사용 설명서, 방송 소프트웨어, 소식, 참여 안내

수정

  • OBS 연결 실패 시 overlay --clip 이 끝나지 않고 멈추던 문제
  • 내려받은 ffmpeg를 PC 점검이 찾지 못하던 문제(PATH만 확인)
  • ffmpeg 없이 자동 클립을 켜면 클립마다 실패하던 문제: 시작 전 확인으로 변경
  • 자동 클립 안내 문구(리플레이 버퍼 길이 부족 등)의 영어 표시: 한국어로 변경

debutkit 0.2: 설정 마법사와 방송 중 자동 클립

목표

  • 명령줄 입력 없이 첫 방송 준비

설정 마법사 5단계

  1. PC 점검: 사양과 프로그램 확인, 문제 항목에 해결 방법 표시
  2. 아바타: 모델 종류별 트래킹 프로그램 안내, 모델 사용 조건(수익 활동, 소속사 활동) 확인
  3. OBS 장면: 버튼 하나로 장면 5종 생성
  4. 채팅과 알림: 치지직, SOOP, Twitch 채널 주소 입력 후 시작
  5. 마무리: 준비 상태 재확인

방송 중 자동 클립

  • 저장 조건: 채팅이 평소보다 크게 몰릴 때, 방장이나 매니저의 !clip
  • 판단 기준: 방송별 평소 채팅량 대비. 시청자가 적은 신입 버튜버 방송에도 적용
  • 동시 송출: 치지직, SOOP 채팅 합산 판단
  • 저장 방식: OBS 리플레이 버퍼. 마법사가 설정을 켜고, OBS 재시작 후 사용 가능

Windows 실행 파일

  • 릴리스 페이지의 zip 압축 해제 후 debutkit-gui.exe 실행

확인 범위

  • 확인 완료: 실제 OBS 33에서 장면 생성부터 !clip 클립 저장까지
  • 미확인: macOS, Linux의 OBS, VTube Studio 실행 상태의 아바타 캡처, SOOP 별풍선 알림 닉네임
  • 문제 제보: GitHub 이슈

debutkit 0.1: 첫 방송 준비 키트 공개

배경

  • 데뷔 준비의 주요 장벽은 아바타 이후 단계: OBS 투명 배경 설정, 치지직과 SOOP 채팅 통합, 후원 알림, PC 사양 확인
  • 개별 방법은 검색 가능하지만 처음 하는 사람에게는 프로그램 여러 개와 설정 수십 개

포함 기능

  • debutkit doctor: 메모리, CPU, 그래픽카드, 저장 공간, OBS와 원격 제어, 트래킹 프로그램 점검. VRM 모델의 수익화, 기획사(법인) 사용 허락 확인
  • debutkit scenes: 대기 화면, 본방송, 토크, 자리 비움, 엔딩 장면 생성. 아바타 투명 배경 캡처, 채팅창과 후원 알림 연결. 기존 장면 유지
  • debutkit overlay: 치지직, SOOP, Twitch 채팅 통합 표시. 내 치지직 채널은 공식 Open API. 데모 채팅과 테스트 후원. 이 PC에서만 열림, 채팅 저장 없음

오픈소스로 만드는 이유

  • 트래킹 프로그램, 해외 플랫폼용 채팅 오버레이는 이미 다수 존재
  • 치지직, SOOP 우선, 데뷔 전 점검부터 방송 중 클립까지 잇는 도구는 없음
  • 기존 프로그램(OBS, VTube Studio, VSeeFace)은 그대로 사용, 연결 부분만 공개
