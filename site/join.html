참여 안내

참여 방법은 프로그램 사용, 개발 참여, 실제 환경 확인, 소속 버튜버 의향 등록의 네 가지입니다. 각 방법은 서로 독립적이며, 하나에 참여해도 다른 항목의 의무는 발생하지 않습니다.

목차

  • 프로그램 사용
  • 개발 참여
  • 실제 환경 확인
  • 소속 버튜버 의향 등록

프로그램 사용

  • 가입이나 동의 절차 없이 사용할 수 있습니다.
  • 설치: 다운로드, 사용법: 사용 설명서

개발 참여

대상버그 제보, 번역, 장면 디자인, 코드
조건커밋마다 DCO 서명(git commit -s). 활동명 사용 가능, 실명 불필요

실제 환경 확인

1.0 출시 전, 개발 환경에서 확인할 수 없는 항목을 실제 PC와 방송 계정으로 확인하고 있습니다. 아래 항목 중 가능한 것만 확인해 보고하면 됩니다.

확인 항목필요 조건방법
마이크, 웹캠 인식macOS 또는 Linux PC설정 마법사 PC 점검 결과의 장치 이름이 실제 장치와 일치하는지 확인
설정 마법사 사용macOS 또는 Linux PC단계별 진행 후 창 닫기. 비정상 종료 여부 확인
아바타 소스VTube Studio 등 실행 중인 PCOBS 장면 생성 후 아바타가 투명 배경으로 표시되는지 확인
치지직 공식 API치지직 채널, 개발자 센터 애플리케이션debutkit chzzk login 후 방송 채팅 표시 확인
SOOP 후원 알림SOOP 방송 중 별풍선 후원알림에 후원자 닉네임이 표시되는지 확인
YouTube 채팅YouTube 방송, API 키debutkit youtube check 방송주소의 모든 단계 정상 여부와 채팅 표시 확인
  1. 최신 릴리스(1.0 후보 포함)를 설치합니다.
  2. 확인한 항목을 진행합니다.
  3. 설정 마법사 마무리 단계에서 점검 결과 복사를 누릅니다.
  4. 실제 환경 확인 보고 양식에 결과를 붙여 넣어 제출합니다.

시청자 닉네임, 채팅 내용, 토큰, API 키, 비밀번호는 보고에 넣지 않습니다. 문제가 있으면 문제 제보 양식도 함께 사용합니다.

소속 버튜버 의향 등록

함께 활동할 버튜버 모집을 준비하고 있습니다. 모집을 시작하면 이 페이지에 신청서 주소를 게시합니다.

원칙내용
비구속신청은 계약이 아니며 제출에 따른 의무가 없음. 이메일 한 통으로 철회와 정보 삭제 요청 가능
사용과 무관신청하지 않거나 신청 후 철회해도 모든 기능을 동일하게 사용
최소 수집활동명, 연락 이메일, 연령대 확인만 수집. 실명, 얼굴 사진, 주소는 수집하지 않음
연령만 14세 미만은 보호자 동의 절차가 필요해 이 신청서로 접수하지 않음. 미성년자의 소속 계약은 보호자 동의 필수
조건 공개캐릭터 IP 귀속, 수익 배분, 계약 기간을 모집 공고에 함께 공개
