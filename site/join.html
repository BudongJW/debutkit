참여 안내

참여 방법 3가지. 모두 서로 독립, 하나를 해도 다른 것의 의무 없음

목차

  • 도구 사용
  • 개발 참여
  • 소속 버튜버 의향 등록

1. 도구 사용

  • 가입, 동의 불필요
  • 다운로드, 사용 설명서

2. 개발 참여

  • 대상: 버그 제보, 번역, 장면 디자인, 코드
  • 조건: 커밋마다 DCO 서명(git commit -s). 활동명 사용 가능, 실명 불필요
  • 안내: CONTRIBUTING.md

3. 소속 버튜버 의향 등록 (준비 중)

함께 활동할 버튜버 모집 예정. 모집 시작 시 이 페이지에 신청서 링크 게시

원칙내용
비구속신청은 계약 아님. 제출해도 의무 없음. 이메일 한 통으로 철회와 정보 삭제
사용과 무관미신청, 신청 후 철회와 관계없이 모든 도구 동일하게 사용
최소 수집활동명, 연락 이메일, 연령대 확인. 실명, 얼굴 사진, 주소 수집 없음
연령만 14세 미만은 보호자 동의 절차 필요, 이 신청서로 접수 불가. 미성년자 소속 계약은 보호자 동의 필수
조건 공개캐릭터 IP 귀속, 수익 배분, 계약 기간을 모집 글에 함께 공개
