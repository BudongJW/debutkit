방송 준비

1/5
  1. debutkit 켜기방송 화면을 만드는 debutkit이 켜져 있습니다.
  2. OBS 연결
    OBS 연결을 확인하는 중
    1. OBS를 켭니다.
    2. OBS 위 메뉴의 도구, WebSocket 서버 설정을 엽니다.
    3. WebSocket 서버 사용을 켜고, 서버 비밀번호를 설정 마법사의 OBS 장면 단계에 넣습니다.
  3. 채팅창, 알림, 캐릭터를 OBS에 넣기
    누르면 지금 OBS 장면에 들어가고 크기와 알림 소리까지 맞춥니다.
  4. 시험 후원으로 확인
    OBS 화면에 알림이 뜨고 소리가 나는지 봅니다. 방송 플랫폼으로는 보내지 않습니다.
  5. 방송 모양 고르기
    방송 스타일, 색, 게임에 맞춘 배치를 고릅니다.
    방송 화면 꾸미기
방송 중에 쓰는 추첨, 뽑기판, 후원 벽, 참여 레이스는 위 메뉴의 방송 중 놀이에 있습니다.

방송을 켜기 전에 한 번 봅니다. 초록은 준비됨, 주황은 확인이 필요한 곳입니다. 단추가 있으면 눌러서 바로 고칩니다.

방송 화면마다 OBS에 넣기를 누르면 지금 OBS 장면에 들어갑니다. 직접 넣으려면 주소를 복사해 OBS의 브라우저 소스에 붙여 넣습니다.

통합 채팅창

자세히(카드 스타일, 이름 색, 움직임, 정렬, 줄 수, 사라짐)

사라짐 시간 0은 계속 표시. 방송 스타일 카드는 방송 화면 꾸미기에서 고른 스타일을 따르고, 카드 스타일을 고르면 채팅창만 다른 스타일로 표시합니다. 직접 넣을 때 크기는 가로 420, 세로 1000.

고른 내용은 바로 위 주소와 OBS에 넣기에 들어갑니다. 이미 넣었다면 OBS에 넣기를 다시 누르면 바뀝니다.

후원, 구독 알림

알림 꾸미기

OBS에 넣기는 알림 소리도 방송으로 보내고 내 헤드폰에도 들리게 맞춥니다(오디오 모니터링). 모양, 위치, 문구, 효과음, 금액별 그림은 알림 꾸미기에서 정합니다. 직접 넣을 때 크기는 방송 화면 전체(1920x1080)이고 소스 속성의 OBS로 오디오 제어를 켭니다.

캐릭터 화면

방송에 쓰는 캐릭터: 확인 중. 캐릭터는 설정 마법사의 캐릭터 단계에서 바꿉니다. VTube Studio 같은 다른 아바타 프로그램을 쓰면 이 화면 대신 그 프로그램 창을 OBS에 넣습니다.

OBS 마이크 음량 대기

얼굴 추적 꺼짐

얼굴 추적 창 열기 휴대폰 얼굴 추적 VMC 송신

웹캠으로 얼굴을 따라가려면 얼굴 추적 창(Chrome, Edge에서 열기), 아이폰으로 하려면 휴대폰 얼굴 추적 화면을 엽니다. 둘 다 켜져 있으면 휴대폰 값을 씁니다.
