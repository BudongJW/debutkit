휴대폰 얼굴 추적

아이폰의 얼굴 인식 카메라로 추적한 머리 움직임과 표정 52개(ARKit)를 받아 캐릭터 화면에 반영합니다. 웹캠 추적보다 눈, 입, 눈썹이 정확하고, ARKit 이름 표정을 가진 모델(퍼펙트 싱크)은 얼굴 전체가 움직입니다. 값은 이 PC의 메모리에서만 처리하며 저장하거나 외부로 보내지 않습니다.

휴대폰 앱 준비

iFacialMocap(App Store 유료, FaceMotion3D는 iFacialMocap 호환 모드)

  1. 휴대폰과 PC를 같은 Wi-Fi(공유기)에 연결
  2. 앱을 실행하고 화면 위쪽에 표시된 IP 주소를 왼쪽에 입력
  3. 연결 시작을 누르면 debutkit이 앱에 송신 요청(앱에서 PC IP를 입력하는 방식도 사용 가능)

VTube Studio(아이폰, 아이패드)

  1. 설정 첫 번째 탭 맨 아래의 3rd Party PC Clients 켜기
  2. 그 아래 표시된 IP 주소를 왼쪽에 입력하고 연결 시작
  3. 연결되면 휴대폰 화면이 어두워지는 것이 정상(배터리 절약)

연결되지 않을 때

  1. 처음 연결할 때 나오는 Windows 보안 경고에서 개인 네트워크 허용
  2. Windows 설정의 네트워크 프로필을 개인 네트워크로(공용이면 차단될 수 있음)
  3. 아이폰 설정의 앱 항목에서 로컬 네트워크 허용
  4. VSeeFace, Warudo, VMagicMirror 등 같은 앱을 받는 프로그램은 끄기
  5. 머리가 반대로 돌면 거울처럼 움직이기를 바꾸고, 위아래가 반대면 위아래 반전 선택

휴대폰 앱의 추적 품질 설정과 발열 대책(장시간 방송 최적화 등)은 각 앱의 안내를 따릅니다.

휴대폰 카메라 영상(OBS 소스)

휴대폰 카메라 영상을 OBS 미디어 소스로 받습니다(실사, 손 캠, 방 안 촬영). OBS 기본 기능(SRT 수신)만 사용하며 암호가 맞는 휴대폰만 연결됩니다. 소리는 보내지 않고 PC 마이크를 사용합니다.

OBS 소스

현재 방송 장면의 왼쪽 위에 [DK] 휴대폰 카메라 소스를 만듭니다. 이미 있으면 포트와 암호만 맞춥니다. 위치와 크기는 OBS에서 바꿀 수 있습니다.

debutkit 앱으로 보내기(낮은 지연)

debutkit 휴대폰 앱의 카메라 영상 모드는 영상을 WebRTC로 OBS 브라우저 소스에 직접 보냅니다(지연이 SRT보다 짧음). 앱을 아래 휴대폰 조작 화면 QR로 등록하고 승인한 뒤 사용합니다. 별도 암호 입력은 필요 없습니다.

앱 영상: 확인 중

OBS 소스 [DK] 휴대폰 카메라(앱)는 평소 투명하고 앱이 영상을 보낼 때만 보입니다. 같은 수신 화면을 일반 브라우저에서 함께 열면 먼저 연결한 화면만 영상을 받습니다.

휴대폰 앱 준비

Larix Broadcaster(아이폰, 안드로이드 무료)

  1. 휴대폰과 PC를 같은 Wi-Fi에 연결(5GHz 권장)
  2. OBS에 소스 만들기를 누른 뒤 휴대폰 카메라로 QR 코드 촬영(안드로이드는 QR 스캐너 앱)
  3. Larix가 열리면 가져오기를 승인하고 방송 버튼(빨간 원)을 누르면 OBS에 영상 표시

다른 SRT 송신 앱(Moblin, IRL Pro 등)

  1. 연결 주소에 위 주소(srt://로 시작), 모드 Caller, 암호와 암호 길이 16 입력

영상이 오지 않을 때

  1. OBS가 처음 수신할 때 나오는 Windows 보안 경고에서 개인 네트워크 허용(obs64)
  2. Windows 네트워크 프로필을 개인 네트워크로, 휴대폰과 PC가 같은 공유기인지 확인
  3. 연결 확인 결과가 연결 대기이면 휴대폰 앱의 주소, 포트, 암호 확인
  4. OBS 소스 상태가 오류이면 다른 프로그램이 같은 포트를 쓰는지 확인하고 포트 변경

휴대폰 조작 화면(추첨, 동작)

같은 Wi-Fi의 휴대폰 브라우저로 시청자 참여 추첨(모집, 마감, 뽑기, 순서)과 3D 캐릭터 동작을 조작하고 후원 추첨 결과를 봅니다. 앱 설치는 필요 없습니다. QR 코드로 등록하고 PC에서 승인한 휴대폰만 조작할 수 있습니다. debutkit 휴대폰 앱(안드로이드, 아이폰)도 같은 QR로 등록하면 휴대폰 카메라 얼굴 추적 값을 보냅니다.

휴대폰 카메라로 QR 코드를 찍어 조작 화면을 연 뒤, 아래 목록에서 휴대폰에 보이는 확인 번호가 같은지 보고 승인합니다. QR은 5분 동안 1대만 등록할 수 있습니다.
