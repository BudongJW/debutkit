시작하기

debutkit 얼굴 추적 값(웹캠 추적 화면, 휴대폰 얼굴 추적)을 VMC 프로토콜로 다른 프로그램에 보냅니다. 머리 회전, 눈, 입, 웃음과 퍼펙트 싱크 표정 52개.

보낼 곳

상태 확인 중

3D 캐릭터의 온몸 자세는 캐릭터 그림 만들기의 포즈 그림에서 VMC로 자세 보내기로 보냅니다. 둘 다 켜면 머리와 표정은 이 화면의 얼굴 추적 값입니다.

켜 두면 다음 오버레이 실행 때도 자동으로 시작합니다. 받는 곳은 이 PC나 같은 네트워크의 내부 주소만 됩니다(얼굴 추적 값이 인터넷으로 나가지 않게).
