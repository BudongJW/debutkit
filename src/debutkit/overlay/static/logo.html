debutkit 로고 만들기

오버레이 설정 화면

방송 로고를 만듭니다. 심볼은 기본 도형(무료) 또는 본인 API 키를 사용하는 생성형 AI로 만들고, 채널 이름은 실제 글꼴의 윤곽선으로 넣어 한글이 깨지지 않습니다. 결과는 SVG(벡터)와 투명 배경 PNG로 저장합니다.

채널 이름과 배치

심볼

만든 심볼은 설정 폴더의 logos 폴더에도 보관합니다(요금이 든 결과를 잃지 않도록).

미리보기와 저장

SVG는 크기를 바꿔도 선명하고 글꼴 설치 없이 열립니다. PNG는 배경 채우기를 끄면 투명 배경입니다. 어두운 방송 화면에 올릴 로고는 글자 색을 밝게 바꿔 따로 저장하십시오.

AI 사용과 권리 안내

  • AI로 만들기를 사용하면 심볼은 생성형 AI(선택한 서비스)가 만듭니다. 결과 SVG에는 AI 생성 표시(IPTC 디지털 소스 유형 메타데이터와 설명)가 들어갑니다. 지우지 마십시오.
  • 심볼 설명과 색은 선택한 AI 서비스로 전송되며 그 서비스의 이용 약관과 요금이 적용됩니다. 설명에 개인정보를 넣지 마십시오.
  • 기존 캐릭터, 로고, 상표, 실존 인물을 흉내 내는 설명은 쓰지 마십시오. 상표로 등록하거나 굿즈에 쓰기 전에는 특허정보검색서비스(KIPRIS)에서 비슷한 상표가 있는지 확인하십시오.
  • 사람의 창작적 수정 없이 AI가 만든 그림은 저작권 보호를 받기 어렵습니다. 심볼을 직접 다듬거나 조합하면 권리 확보에 유리합니다.
