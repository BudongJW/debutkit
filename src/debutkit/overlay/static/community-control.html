팬 커뮤니티

내 커뮤니티

트게더처럼 내 팬들이 모이는 커뮤니티(공지, 방송 일정, 자유와 팬아트 게시판, 댓글, 출석과 포인트)를 만듭니다. 커뮤니티는 내 Cloudflare 무료 계정에 올라가 PC를 꺼도 열려 있고, debutkit이 방송 중 채팅, 출석, 참여 추첨, 방송 화면과 이어 줍니다.

운영자는 스트리머 본인입니다. 개인정보 처리방침과 이용 규칙은 자동으로 들어가며, 신고된 글 확인과 가리기, 탈퇴와 데이터 내보내기 기능이 있습니다. 회원 정보는 플랫폼 계정 번호와 닉네임만 받고 이메일, 비밀번호, 전화번호는 받지 않습니다.

커뮤니티 만들기

  1. Cloudflare 무료 계정을 만듭니다(카드 등록 필요 없음).
  2. 대시보드의 내 프로필, API 토큰에서 토큰 만들기, "Cloudflare Workers 편집" 템플릿을 고르고 권한에 계정 D1 편집을 더해 만듭니다.
  3. 만든 토큰을 아래에 붙여 넣고 올리기를 누릅니다. 토큰은 이 PC에만 암호화해 보관합니다.
플랫폼 로그인(선택)

방송 채팅 인증(!인증 숫자)은 설정 없이 됩니다. 방송이 없을 때도 가입받으려면 서비스별 개발자 화면에서 앱을 만들고 Client ID와 Secret을 넣습니다. 돌아올 주소는 올린 뒤 아래에 나옵니다. 네이버와 카카오는 검수가 필요해 넣지 않았습니다.

이 PC 연결 지우기

이 PC에 보관한 Cloudflare 토큰과 커뮤니티 연결 정보만 지웁니다. 커뮤니티와 글은 Cloudflare에 그대로 남으며, 완전히 닫으려면 관리 화면에서 데이터를 내보낸 뒤 Cloudflare 대시보드에서 Worker, D1, KV를 지웁니다.
