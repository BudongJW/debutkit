오버레이 설정 화면

칸을 누르면 방송 화면에서 그 칸이 열립니다. 상품 배치는 판을 만들 때 이 PC의 debutkit이 무작위로 정하며, 방송 화면에는 열린 칸의 상품만 전달됩니다.

뽑기판

배치가 보이는 중입니다. 이 화면이 방송에 나가지 않도록 주의.

되돌리기는 마지막으로 연 칸을 다시 덮습니다(기록에는 취소로 남음). 섞기, 처음부터 다시는 새 배치와 새 확인 값을 만듭니다. 위험한 버튼은 두 번 눌러야 실행됩니다.

기록

    공정성 확인

    판을 만들 때 방송 화면에 SHA-256 값을 공개합니다. 판이 끝나면 소금값과 배치로 만든 확인 문자열을 공개하므로, 누구나 그 문자열의 SHA-256이 처음 값과 같은지 확인할 수 있습니다.

    확인 문자열(첫 줄 소금값, 다음 줄부터 번호:내용)

      판 목록

        판마다 설정, 배치, 열린 칸, 기록을 따로 저장합니다. 판을 바꾸면 방송 화면도 바로 바뀝니다.

        방송 화면

        OBS 브라우저 소스로 추가합니다. 권장 크기 1920x1080, 배경은 투명합니다.

        OBS 독 메뉴의 사용자 지정 브라우저 독에 이 주소를 넣으면 OBS 안에서 이 화면을 쓸 수 있습니다. 배치 보기를 켠 독은 방송에 나가지 않도록 주의.
