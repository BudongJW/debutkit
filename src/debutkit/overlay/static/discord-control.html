디스코드 합방

1. 합방 참여자 화면(디스코드 음성 위젯)

디스코드 음성 채널에서 지금 말하는 사람을 방송 화면에 보여 줍니다. 디스코드 공식 기능(StreamKit)을 쓰며, 이 PC의 디스코드 앱이 켜져 있어야 합니다.

  1. StreamKit을 열고 OBS용 설치를 눌러 디스코드에서 허락합니다.
  2. 음성 위젯에서 서버와 음성 채널을 고르고, 오른쪽의 주소를 복사해 아래에 붙여 넣습니다.
  3. 모양을 고른 뒤 OBS에 넣기를 누릅니다.
직접 넣을 때(주소와 사용자 지정 CSS)

2. 참여자 그림(선택)

합방 참여자마다 디스코드 프로필 사진 대신 캐릭터 그림을 보여 주고, 말할 때는 다른 그림(입 벌린 그림 등)으로 바꿉니다. 그림을 쓰기 전에 참여자에게 먼저 물어보십시오.

사용자 ID: 디스코드 설정의 고급에서 개발자 모드를 켜고, 참여자 이름을 오른쪽 클릭해 사용자 ID 복사. 기본 프로필 사진을 쓰는 사람은 그림을 바꿀 수 없습니다.

3. 방송 알림(디스코드 웹훅)

내 디스코드 서버의 채널에 방송 시작과 방송 끝 요약을 자동으로 올립니다.

  1. 디스코드에서 알림을 올릴 채널의 설정(톱니바퀴), 연동, 웹후크, 새 웹후크를 누릅니다.
  2. 웹후크 URL 복사를 눌러 아래에 붙여 넣고 저장한 뒤 시험 보내기를 누릅니다.

방송 시작은 실제 방송 채팅이나 후원이 처음 올 때, 끝 요약은 오버레이를 멈출 때 보냅니다. @everyone 같은 호출은 보내지 않습니다. 웹훅 주소는 이 PC에만 암호화해 보관합니다.

예시 참여자 세 명으로 본 모습입니다(가운데 사람이 말하는 중). 실제 화면은 디스코드 음성 채널에 들어온 사람이 나옵니다. 디스코드가 위젯 모양을 바꾸면 이 꾸미기가 맞지 않을 수 있습니다.
