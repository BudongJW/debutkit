debutkit 마스코트 캐스트 (시안 v0.1)
====================================

[ draft ]  캐스트 시안, 투명 배경 512px PNG
- debi       A 데비(데뷔 준비생): debutkit의 얼굴. 시작하기 목록, PNGTuber 기본값, VRM 샘플, 대표 그림
- mai        B 마이(리본 마이크): 로고와 앱 아이콘, 마이크 점검, 이모트
- cue        C 큐(무대 감독): 설정 마법사 안내, 방송 직전 점검 진행, 오류 화면
- bubbles    뽀글이들(말풍선 무리): 채팅 예시, 레이스 주자, 빈 화면, 팔로우 알림
- capsule    캡슐(뽑기 캡슐): 후원 추첨, 뽑기판, 후원 알림 기본 그림
- cuckoo     뻐꾹(뻐꾸기 시계새, 보조): 대기, 자리 비움 화면의 카운트다운
- dessaengi  데생이(데생 인형, 보조): 캐릭터 없음 화면, 그림 만들기 안내
- pad        패드(게이머 너구리, 후보): 게임 패키지

만든 방법
- 모델: FLUX.1 schnell(Apache-2.0), AI Horde(자원봉사자 GPU)에서 실행
- 배경: 테두리와 이어진 단색 배경만 지움(debutkit logo_image.key_background)
- 기록: manifest.json(파일별 지시문, 시드, 작업자, 날짜). 같은 지시문과 시드로 다시 만들 수 있음

캐릭터 기준(새 그림을 만들 때 유지)
- 공통: SD 비율, 굵은 검은 외곽선, 단색 채색, 스티커 그림체(stream2clip 키리와 같은 화풍, 형제 브랜드)
- 색: debutkit은 라벤더, 민트, 노랑(+ 코랄 포인트). 키리(분홍, 크림, 검정)와 겹치지 않게
- 데비: 라벤더 옆 포니테일, 노란 별 머리핀, 민트 눈, 라벤더 재킷(코랄, 민트 테두리), 무대 마이크
- 마이: 1950년대 리본 마이크, 라벤더 몸과 은색 가로 막대, 막대 위 얼굴, 양옆 음파(민트) 귀, 노란 손
- 큐: 민트 머리, 남색 베레모(노란 별), 헤드셋, 분홍 목도리, 슬레이트

유의 사항
- 시안이며 사람 손질 전. AI 생성물 자체는 저작물로 보호되지 않아 대표 그림은 사람이 손질하거나 벡터로 다시 그림
- 표정, 각도, 입 벌림과 눈 감음(PNGTuber 4상태)은 Qwen-Image-Edit(Apache-2.0)로 같은 캐릭터를 편집해 만들 예정
- 방송 플랫폼 이모트로 올리기 전 각 플랫폼의 규격과 AI 생성물 정책 확인
