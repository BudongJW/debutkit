# 개발 계획

## 완료 버전

### 0.1

| 기능 | 검증 내용 |
|---|---|
| PC 점검(`doctor`), VRM 사용 조건 확인(`--avatar`) | 실제 Windows PC 실행, 단위 테스트 |
| OBS 장면 5종(`scenes`) | 실제 OBS 33.0.1(Windows)에서 장면 5종, 소스 8개 생성. 재실행 시 기존 장면 유지. 장면 화면으로 배치 확인 |
| 통합 채팅창과 알림(`overlay`) | 브라우저로 데모, 시험 메시지 확인. CHZZK, SOOP 실방송 채팅의 닉네임 해석 확인(2026-11-21) |

### 0.2

| 기능 | 검증 내용 |
|---|---|
| 설정 마법사(PySide6) | 가짜 동작 단위 테스트 7개. 실제 OBS 33 연결, 장면 생성, 오버레이, 자동 클립을 창에서 실행 |
| 자동 클립(`overlay --clip`) | 실제 OBS 33에서 `!clip` 입력 13초 후 24초 길이 클립 저장 |
| 리플레이 버퍼 설정(`scenes --replay-buffer`) | 실제 OBS 33에서 설정 즉시 저장, 버퍼는 OBS 재시작 후 사용 가능. 프로필 전환 방식은 동작하지 않고 프로필이 남아 채택하지 않음 |
| Windows 실행 파일 | 로컬 빌드 zip 72 MB(압축 해제 시 163 MB). 파이썬 없이 `--version`, `doctor`, `scenes --dry-run`, 창 열기와 닫기 확인 |

### 0.3

| 기능 | 검증 내용 |
|---|---|
| ffmpeg 다운로드(`setup --ffmpeg`, 설정 마법사 버튼) | 단위 테스트(진행률, 재점검). 다운로드 주소 응답과 파일 크기(114,768,076 바이트) 일치 확인. 전체 다운로드는 미실행 |
| 치지직 로그인(`chzzk login`, `logout`, 설정 마법사 버튼) | 단위 테스트(한국어 오류, 토큰 삭제). 실제 계정 로그인 미확인 |
| 자동 클립 시작 전 ffmpeg 확인, 한국어 안내 | 단위 테스트 |
| OBS 연결 실패 시 `overlay --clip` 미종료 문제 수정 | 재현 후 수정, 회귀 테스트 |
| 프로젝트 사이트 | 내부 링크와 표기 원칙 테스트, GitHub Pages 배포, 기존 블로그 주소 이동 확인 |
| 릴리스 | CI(Windows, macOS, Linux와 Python 3.10, 3.12, 3.14) 통과. 태그 빌드 zip 68 MB |

## 미확인 항목

- SOOP 별풍선, 애드벌룬, 영상풍선의 닉네임 위치(실제 후원 패킷 필요)
- VTube Studio 실행 중 아바타 창 지정 문자열(`VTube Studio:UnityWndClass:VTube Studio.exe`)
- macOS, Linux의 OBS 장면 구성(소스 종류 이름)과 마이크, 웹캠 인식
- 치지직 공식 API의 실제 계정 사용
- YouTube 공식 API의 실제 방송 사용(API 키만으로 채팅 수신 가능 여부 포함)
- 고급 출력 모드(AdvOut)에서 리플레이 버퍼 설정
- 설치 프로그램의 ffmpeg 다운로드 작업(실제 115 MB 다운로드)
