# 로드맵

## 0.1 (완료)

| 기능 | 확인 |
|---|---|
| `doctor` 방송 준비 점검, `--avatar` VRM 사용 조건 | 실제 Windows PC 실행, 단위 테스트 |
| `scenes` OBS 장면 5종 | 실제 OBS 33.0.1(Windows)에서 장면 5종, 소스 8개 생성. 재실행 시 건너뜀. 장면 스크린샷으로 배치 확인 |
| `overlay` 통합 채팅과 알림 | 브라우저로 데모, 테스트 확인. CHZZK, SOOP 실방송 채팅 닉네임 해석 확인(2026-11-21) |

## 0.2 (완료): 설치 없는 실행, 방송 중 자동 클립

| 기능 | 확인 |
|---|---|
| 설정 마법사(PySide6) | 가짜 동작 단위 테스트 7개. 실제 동작으로 OBS 33 연결, 장면, 오버레이, 자동 클립까지 창에서 실행 |
| 자동 클립 `overlay --clip` | 실제 OBS 33에서 `!clip` 13초 뒤 24초 길이 클립 저장 |
| `scenes --replay-buffer` | 실제 OBS 33: 설정 즉시 저장, **버퍼는 OBS 재시작 후 사용 가능**. 프로필 전환 방식은 동작하지 않고 프로필이 남아 미사용 |
| Windows 실행 파일 | 로컬 빌드 zip 72 MB(해제 시 163 MB). 파이썬 없이 `--version`, `doctor`, `scenes --dry-run`, 창 열고 닫기 확인 |

## 0.3 (완료): 외부 명령 없는 준비

| 기능 | 확인 |
|---|---|
| `setup --ffmpeg`, 마법사 ffmpeg 내려받기 | 단위 테스트(진행률, 재점검). 실제 내려받기는 릴리스 전 확인 필요 |
| `chzzk login`, `logout`, 마법사 로그인 버튼 | 단위 테스트(한국어 오류, 토큰 삭제). 실제 계정 로그인 미확인 |
| 자동 클립 시작 전 ffmpeg 확인, 안내 한국어 | 단위 테스트 |
| `overlay --clip` 실패 시 멈춤 수정 | 재현 후 수정, 회귀 테스트 |
| 프로젝트 사이트 | 내부 링크, 표기 원칙 테스트 |

## 미확인 항목

- SOOP 별풍선, 애드벌룬, 영상풍선의 닉네임 칸(실제 후원 패킷 필요)
